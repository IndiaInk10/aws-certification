강의를 **순서대로 한 모듈씩** 따라가고, 서비스 노트로 깊이를 채우고, 문제로 확인합니다.

## 자격증

| 자격증 | 상태 | 모듈 | 문항 | 시작 |
|---|---|---|---|---|
| **AWS Certified Cloud Practitioner (CLF-C02)** | 진행 중 | 13 | 1,142 | [[00-learning-path]] |

다른 자격증은 아직 없습니다. 추가 방법은 [[adding-certifications]]에 있습니다.

## 기능

| | |
|---|---|
| **학습 경로** | 모듈별 진행 상태를 체크하며 순서대로 진행 |
| **문제 풀이** | 실제 시험(Pearson VUE)과 같은 화면 구조로 응시 · 채점 |
| **오답노트** | 틀린 문항이 자동으로 쌓이고 간격 반복으로 복습 |
| **노트 그래프** | 강의 · 서비스 · 문제은행이 어떻게 이어져 있는지 |

## 공통 문서

- [[references]] — 모든 자료의 출처 · 라이선스 · 수집 방법
- [[adding-certifications]] — 폴더 구조와 절차

## 원칙

**한 번에 다 보지 않는다.**

각 모듈 노트는 항상 같은 5칸입니다 — `왜 필요한가` · `새로 나오는 서비스` · `강의 내용` · `여기까지의 지도(누적)` · `셀프 체크`.
전체를 조망하는 지도는 **완주 후 복습용**으로 따로 둡니다.
