자격증마다 `content/docs/<자격증-slug>/` 하나를 만듭니다. 서로 완전히 독립적입니다.

## 폴더 구조

```
content/docs/
 index.md 자격증 허브 (여기에 한 줄 추가)
 참고 자료.md 출처 기록 (여기에 섹션 추가)
 새 자격증 추가하기.md

 aws-clf-c02/ 자격증 하나 = 폴더 하나
 00-MOC/ 지도 노트
 00 학습 경로.md 시작점. 모듈 순서
 헷갈리는 서비스 비교.md
 전체 서비스 맵.md
 <자격증> 시험 개요.md
 20-Course/ 모듈 노트 (본체)
 10-Services/ 서비스 노트
 30-Exam/ 문제은행 · 오답노트
 90-Templates/ 템플릿
 images/m1..mN/ 강의 이미지

 aws-saa-c03/ 다음 자격증도 같은 모양
 ...
```

`slug`는 URL이 되므로 소문자·하이픈으로 (`aws-saa-c03`, `aws-aif-c01`).

## 절차

### 1. 뼈대 복사

`90-Templates/` 의 템플릿을 새 폴더로 복사합니다.

| 템플릿 | 쓰임 |
|---|---|
| `서비스 노트.md` | 서비스 하나당 하나 |
| `단계 노트.md` | 모듈 하나당 하나 (5칸 구조) |

### 2. 강의 추출

Skill Builder 코스라면 [[references]]의 `__fetchCourse()` 방법을 그대로 씁니다.
모듈 ID만 바꾸면 됩니다.

> [!important] 목차를 먼저 확인하세요
> CLF-C02 때 실제 목차를 안 보고 모듈 구성을 추정했다가 전부 다시 만들었습니다.
> **반드시 실제 목차를 읽은 뒤** 모듈 노트를 생성하세요.

### 3. 서비스모듈 매핑

추측하지 말고 **추출된 본문에서 산출**합니다.
각 서비스 이름이 어느 모듈에서 가장 많이 언급되는지로 배정하면 정확합니다.

### 4. 문제은행

- 라이선스가 재배포를 허용하는 것만 사용 (MIT 등)
- 출처를 [[references]]에 반드시 기록
- 문항 형식은 CLF-C02와 동일하게 맞추면 웹사이트 퀴즈 UI가 그대로 동작합니다

### 5. 등록

- [[index]] 표에 한 줄 추가
- [[references]]에 출처 섹션 추가
- `content/docs/<slug>/meta.json` 으로 사이드바 이름·순서 지정

## 지켜야 할 원칙

1. **누적형** — 전체를 한 번에 펼치지 말고 모듈 순서대로 한 겹씩
2. **전체 지도는 완주 후** — 처음에 열지 말라고 명시
3. **출처 기록** — 어디서 왔는지 모르는 자료를 넣지 않는다
