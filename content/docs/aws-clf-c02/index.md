AWS의 가장 기초 자격증입니다. 특정 기술을 깊게 파기보다 **클라우드가 무엇이고 AWS에 어떤 서비스가 있는지** 전반을 묻습니다.

## 시험 정보

| | |
|---|---|
| 문항 · 시간 | 65문항 / 90분 |
| 합격 기준 | 1000점 만점 중 **700점** |
| 문제 유형 | 객관식(정답 1개) · 복수 응답(정답 2개 이상) |
| 응시료 | USD 100 |
| 유효기간 | 3년 |

도메인별 출제 비중과 자주 나오는 함정은 [[exam-overview]]에 정리돼 있습니다.

## 시작하기

> [!important] [[00-learning-path]] 하나만 열면 됩니다

모듈 노트 하단의 **완료 표시**를 누르면 학습 경로의 진행률에 반영됩니다.
