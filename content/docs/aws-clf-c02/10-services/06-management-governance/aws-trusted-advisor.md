## 한 줄로 말하면

내 계정을 AWS 모범 사례에 비추어 자동으로 점검하고, 다섯 개 범주로 **권장 사항**을 내놓습니다.

## 핵심 개념

- **5개 범주** — **비용 최적화 / 성능 / 보안 / 내결함성 / 서비스 한도(할당량)** 입니다. 이 다섯 개는 그대로 외워 두시기 바랍니다.
- **신호등 표시** — 점검 항목마다 조치 권장(빨강), 조사 권장(노랑), 문제 없음(초록)으로 표시해 우선순위를 알려 줍니다.
- **대표적인 점검 예시** — 사용률이 낮은 EC2 인스턴스, 퍼블릭으로 열린 S3 버킷, **모든 IP에 포트를 열어 둔 보안 그룹**, MFA가 걸려 있지 않은 루트 사용자, 다중 AZ가 아닌 RDS, 한도에 근접한 서비스 할당량 등입니다.
- **권장할 뿐 고쳐 주지는 않습니다** — 실제 조치는 사용자가 직접 합니다.
- **계정 단위 자동 점검** — 내가 질문에 답할 필요 없이 계정을 스캔해 결과를 바로 보여 준다는 점이 Well-Architected Tool과 갈리는 지점입니다.

## 요금 모델

- **Trusted Advisor 자체에 붙는 요금은 없습니다.** 대신 **가입한 지원 플랜에 따라 볼 수 있는 점검 범위가 달라집니다.**
- Basic·Developer 플랜에서는 보안과 서비스 한도 중심의 **핵심 점검 일부만** 열립니다.
- Business·Enterprise 플랜에서는 **다섯 범주 전체 점검**과 API 접근, 알림 기능까지 쓰실 수 있습니다.

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[aws-compute-optimizer]] | Trusted Advisor는 **5개 범주 전반의 권장 사항**, Compute Optimizer는 **리소스 크기(라이트사이징)** 권장입니다 |
| [[aws-well-architected-tool]] | Trusted Advisor는 **계정을 자동으로 점검**해 줍니다. Well-Architected Tool은 **워크로드를 두고 내가 질문에 답하며 검토**합니다 |
| [[aws-cost-explorer]] | Cost Explorer는 **지출을 분석해 보여 주고**, Trusted Advisor는 **낭비되고 있는 리소스를 지목**합니다 |

## 시험 포인트

- [ ] **"서비스 한도(할당량)에 근접했다"** 는 다섯 범주 중 Trusted Advisor에만 있는 항목입니다. 강력한 신호입니다
- [ ] "**무제한 액세스를 허용하는 보안 그룹을 찾아라**"처럼 계정 전체를 훑어 위험 설정을 골라내는 문제는 Trusted Advisor입니다
- [ ] 5개 범주를 그대로 나열하게 하는 문제가 자주 나옵니다
- [ ] **지원 플랜 등급에 따라 점검 범위가 다릅니다.** "모든 플랜에서 전체 점검을 제공한다"는 오답입니다
- [ ] 점검과 권장만 하고 자동 조치는 하지 않습니다
- [ ] "인스턴스 유형을 무엇으로 바꾸라"는 크기 권장은 Compute Optimizer 쪽입니다
