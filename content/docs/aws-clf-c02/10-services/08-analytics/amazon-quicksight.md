# Amazon QuickSight

> BI 대시보드·시각화

| | |
|---|---|
| **카테고리** | 08-분석 |
| **배우는 모듈** | [[08-ai-ml-analytics]] |
| **문제은행 출현** | 15회 |
| **상태** | - 미학습 |

## 한 줄로 말하면

분석한 결과를 **차트와 대시보드로 그려서** 경영진과 현업이 바로 볼 수 있게 만드는 비즈니스 인텔리전스(BI) 서비스입니다.

## 핵심 개념

- **시각화가 목적입니다** — 숫자 표만으로는 의사 결정이 어렵습니다. QuickSight는 그 데이터를 **그래프·대시보드**로 바꿔 줍니다. 데이터를 만드는 서비스가 아니라 **보여 주는** 서비스입니다.
- **여러 소스를 붙일 수 있습니다** — S3, Athena, Redshift, RDS 같은 AWS 데이터 소스는 물론 외부 데이터도 연결해 하나의 대시보드에 모읍니다.
- **대시보드를 공유합니다** — 만든 대시보드를 조직 구성원에게 공유하거나 애플리케이션에 삽입해 보여 줄 수 있습니다.
- **서버리스이고 브라우저에서 동작합니다** — BI 서버를 세우거나 클라이언트 프로그램을 설치하실 필요가 없습니다.
- **분석 파이프라인의 마지막 칸입니다** — Glue로 정리하고, Athena나 Redshift로 조회하고, **QuickSight로 보여 주는** 순서를 기억하시면 됩니다.

## 요금 모델

- **사용자(사람) 단위**로 과금합니다. 대시보드를 만드는 작성자와 보기만 하는 열람자의 요금이 다릅니다.
- 열람자는 실제로 대시보드를 **본 만큼**만 계산하는 방식도 선택하실 수 있어, 가끔 보는 조직에서 비용을 낮출 수 있습니다.
- 데이터를 메모리에 올려 빠르게 조회하는 인메모리 엔진(SPICE)의 **용량**에도 요금이 붙습니다.

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[amazon-athena]] | Athena는 SQL로 **결과를 뽑고**, QuickSight는 그 결과를 **그림으로 보여 줍니다.** "시각화·대시보드"라는 단어가 나오면 QuickSight입니다 |
| [[amazon-redshift]] | Redshift는 데이터를 **저장하고 분석하는** 창고이고, QuickSight는 창고에서 꺼낸 결과를 **표시하는 화면**입니다 |
| [[amazon-cloudwatch]] | CloudWatch 대시보드는 **AWS 리소스의 운영 지표**를 봅니다. QuickSight는 **비즈니스 데이터**를 봅니다 |

## 시험 포인트

- [ ] 문제에 **"대시보드", "시각화", "비즈니스 인텔리전스(BI)", "경영진에게 보고"** 가 나오면 QuickSight입니다
- [ ] **"차트로 표현", "데이터를 한눈에 볼 수 있게"** 도 같은 신호입니다
- [ ] 과금 기준은 **사용자 단위**입니다. 스캔량이나 인스턴스 시간으로 쓴 선택지는 다른 서비스의 설명입니다
- [ ] 데이터를 **가공하거나 질의하는** 역할을 QuickSight에 붙여 놓은 선택지는 함정입니다. 그것은 Glue와 Athena의 일입니다
