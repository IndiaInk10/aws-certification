## 한 줄로 말하면

텍스트를 **한 언어에서 다른 언어로** 옮겨 주는 기계 번역 서비스입니다.

## 핵심 개념

- **입력도 텍스트, 출력도 텍스트입니다** — 달라지는 것은 **언어**뿐입니다. 이 점이 다른 AI 서비스와 갈리는 지점입니다.
- **다국어 서비스에 씁니다** — 웹사이트와 앱을 여러 나라 말로 제공하거나, 해외 고객 문의를 사내 언어로 바꿔 볼 때 씁니다.
- **원본 언어를 자동으로 감지합니다** — 무슨 언어인지 지정하지 않아도 알아서 판별한 뒤 번역합니다.
- **실시간 번역과 일괄 번역** — 채팅처럼 즉시 번역해야 하는 경우와, 문서 뭉치를 한 번에 번역하는 경우를 모두 지원합니다.
- **용어집을 지정할 수 있습니다** — 브랜드명이나 전문 용어처럼 **이렇게 번역해야 한다**고 정해 둔 단어를 반영합니다.
- **완성형 API입니다** — 번역 모델을 직접 만들 필요가 없습니다.

## 요금 모델

- **번역한 문자 수**를 기준으로 과금합니다.
- 프리 티어가 있어 가입 후 일정 기간 매달 일정 문자 수까지 무료로 번역하실 수 있습니다.
- 용어집을 쓰거나 특정 도메인에 맞춘 번역을 쓰면 문자당 요금이 달라집니다.

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[amazon-comprehend]] | Comprehend는 텍스트의 **의미와 감정**을 뽑아내고, Translate는 **언어만 바꿉니다.** "무슨 뜻인지 파악"이면 Comprehend, "다른 나라 말로"면 Translate입니다 |
| [[amazon-polly]] | Polly는 글을 **소리**로 바꾸고, Translate는 글을 **다른 언어의 글**로 바꿉니다. 형식이 바뀌는지 언어가 바뀌는지로 가르시면 됩니다 |
| [[amazon-transcribe]] | Transcribe는 **음성**을 텍스트로 옮깁니다. Translate의 입력은 처음부터 텍스트입니다 |

## 시험 포인트

- [ ] 문제에 **"번역", "다국어 지원", "여러 언어로 웹사이트 제공", "해외 고객의 언어"** 가 나오면 Translate입니다
- [ ] 입력과 출력이 **둘 다 텍스트인데 언어만 달라지면** Translate입니다
- [ ] 과금 기준은 **번역한 문자 수**입니다
- [ ] "외국어 통화를 우리말 텍스트로 정리"처럼 단계가 여럿이면 **Transcribe(받아쓰기) → Translate(번역)** 순서입니다
