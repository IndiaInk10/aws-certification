## 한 줄로 말하면

AWS에서 **가상 서버를 몇 분 만에 빌려 쓰는** 서비스이고, 컴퓨팅의 기본 단위입니다.

## 핵심 개념

- **가상 서버(인스턴스)** — Elastic Compute Cloud의 약자이고 실체는 가상 머신입니다. 물리 호스트 한 대를 여러 인스턴스가 나눠 쓰되 하이퍼바이저가 서로를 격리합니다. 이것을 **멀티테넌시**라고 합니다.
- **AMI와 인스턴스 유형** — 시작할 때 반드시 이 두 가지를 고릅니다. **AMI**는 운영 체제와 소프트웨어가 미리 들어 있는 템플릿이고, **인스턴스 유형**은 vCPU·메모리·네트워크 성능 같은 하드웨어 사양입니다.
- **인스턴스 패밀리 다섯 가지** — 범용(균형), 컴퓨팅 최적화(CPU), 메모리 최적화(메모리), 가속 컴퓨팅(GPU 등 하드웨어 가속기), 스토리지 최적화(로컬 디스크 I/O)로 나뉩니다. 워크로드에 맞는 것을 고르시면 됩니다.
- **비관리형 서비스** — AWS는 물리 하드웨어와 하이퍼바이저까지만 책임집니다. **게스트 OS 패치, 애플리케이션, 보안 그룹 설정은 전부 고객 몫**입니다. 공동 책임 모델 문제에서 자주 나옵니다.
- **스케일 업과 스케일 아웃** — 인스턴스를 중지하고 크기를 바꾸면 스케일 업이고, 대수를 늘리면 스케일 아웃입니다. 클라우드에서는 여러 AZ에 나눠 배포하는 **스케일 아웃이 기본**입니다.
- **접속 방법** — Linux는 SSH, Windows는 RDP로 접속하고 키 페어의 프라이빗 키는 고객이 보관합니다. [[aws-systems-manager]]의 Session Manager를 쓰시면 키 없이도 안전하게 접속하실 수 있습니다.

## 요금 모델

- **실행 중인 시간**을 기준으로 과금하고, **Linux 인스턴스는 초 단위**로 계산합니다. **중지·종료하면 인스턴스 요금이 멈춥니다.**
- 요금 옵션은 다섯 가지입니다 — **온디맨드**(약정 없음), **절감형 플랜**(시간당 금액을 1·3년 약정, 인스턴스 종류가 바뀌어도 적용), **예약 인스턴스**(특정 인스턴스를 1·3년 약정), **스팟 인스턴스**(남는 용량을 싸게 쓰되 회수될 수 있음), **전용 호스트**(물리 서버 독점).
- 인스턴스에 붙은 **[[amazon-ebs]] 볼륨 요금과 아웃바운드 데이터 전송 요금은 별도**입니다.
- 프리 티어로 `t2.micro`·`t3.micro` 급 인스턴스를 매월 정해진 시간만큼 무료로 쓰실 수 있습니다.

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[aws-lambda]] | EC2는 **서버를 내가 띄우고 OS까지 관리**하고, Lambda는 **서버가 아예 없이 코드만** 올립니다. "서버 관리를 없애고 싶다"면 Lambda입니다. |
| [[aws-fargate]] | 둘 다 컨테이너를 돌릴 수 있지만, EC2는 컨테이너 호스트를 내가 관리하고 Fargate는 **호스트 자체가 보이지 않습니다.** |
| [[amazon-lightsail]] | Lightsail은 사양과 요금이 묶인 **정액제 패키지**이고, EC2는 사양·네트워크·요금 옵션을 하나하나 고르는 **유연한 쪽**입니다. |
| [[aws-outposts]] | EC2는 AWS 리전 안에서 돌아가고, Outposts는 **같은 EC2를 고객 데이터 센터 안에서** 돌립니다. |

## 시험 포인트

- [ ] 문제에 **"가상 서버", "OS를 직접 제어", "기존 애플리케이션을 그대로 옮긴다"** 가 나오면 EC2입니다
- [ ] **"중지하거나 종료하면 어떻게 되나"** → 인스턴스 요금은 멈추지만 **EBS 볼륨 요금은 계속 나갑니다.** 자주 나오는 함정입니다
- [ ] **"메모리에서 대규모 데이터를 처리"** 는 메모리 최적화, **"로컬에 저장된 데이터, 높은 디스크 처리량"** 은 스토리지 최적화로 갈립니다
- [ ] **"중단을 허용한다 + 남는 용량"** 은 스팟, **"약정 없이 시작"** 은 온디맨드, **"3년간 예측 가능"** 은 예약 인스턴스나 절감형 플랜입니다
- [ ] **"물리 서버 배치까지 완벽하게 제어"** 는 전용 인스턴스가 아니라 **전용 호스트**입니다
- [ ] 공동 책임 모델에서 EC2는 **비관리형**입니다. 게스트 OS 패치를 AWS가 해 준다고 쓴 선택지는 오답입니다
