# AWS CodeDeploy

> 배포 자동화

| | |
|---|---|
| **카테고리** | 11-마이그레이션-기타 |
| **배우는 모듈** | *이 코스에서는 다루지 않음 (문제은행 전용)* |
| **문제은행 출현** | 12회 |
| **상태** | - 미학습 |

## 한 줄로 말하면

빌드가 끝난 애플리케이션을 **여러 대상에 자동으로, 다운타임 없이 배포**해 주는 서비스입니다.

## 핵심 개념

- **배포 담당** — 개발 파이프라인에서 **마지막 단계**를 맡습니다. 서버에 접속해 파일을 복사하고 서비스를 재시작하던 수작업을 자동화합니다.
- **다양한 배포 대상** — [[amazon-ec2]] 인스턴스, **온프레미스 서버**, [[aws-lambda]] 함수, [[amazon-ecs]] 서비스에 배포할 수 있습니다. AWS 밖의 서버에도 배포된다는 점이 특징입니다.
- **배포 방식 두 가지** — **인플레이스(in-place)** 는 기존 인스턴스에서 앱을 교체하고, **블루/그린(blue/green)** 은 새 환경을 따로 띄운 뒤 트래픽을 옮깁니다. 블루/그린은 **다운타임을 없애고 되돌리기 쉽게** 해 줍니다.
- **자동 롤백** — 배포 중 오류가 나거나 지표가 나빠지면 **직전 정상 버전으로 자동 복구**합니다. 실패한 배포가 서비스를 오래 망가뜨리지 않게 막아 줍니다.
- **점진적 배포** — 한 번에 전부 바꾸지 않고 일부 인스턴스씩 순차적으로 교체할 수 있어, 문제가 생겨도 영향 범위가 제한됩니다.

## 요금 모델

- **EC2, Lambda, ECS 등 AWS 리소스에 배포하는 것은 무료입니다.** CodeDeploy 사용료가 붙지 않고, 배포 대상 리소스 요금만 냅니다.
- **온프레미스 서버에 배포**할 때만 **인스턴스 업데이트 건당** 요금이 발생합니다.
- 배포 과정에서 아티팩트를 두는 **S3 저장 요금** 등 주변 리소스 요금은 별도입니다.

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[aws-codebuild]] | CodeBuild는 **배포할 결과물을 만들고**, CodeDeploy는 그 결과물을 **실제 서버에 올립니다** |
| [[aws-codepipeline]] | CodeDeploy는 파이프라인의 **배포 단계 하나**이고, CodePipeline은 **소스·빌드·배포를 순서대로 잇는** 전체 흐름입니다 |
| [[aws-elastic-beanstalk]] | Beanstalk은 **인프라 생성부터 배포까지 통째로** 알아서 해 주고, CodeDeploy는 **이미 있는 대상에 애플리케이션만** 배포합니다 |

## 시험 포인트

- [ ] 문제에 **"애플리케이션 배포를 자동화"**, **"다운타임 없이 새 버전 배포"**, **"배포 실패 시 자동 롤백"** 이 나오면 CodeDeploy입니다
- [ ] **온프레미스 서버에도 배포할 수 있다**는 점이 다른 Code 서비스와 구분되는 특징입니다
- [ ] **블루/그린 배포**라는 단어가 보이면 CodeDeploy를 먼저 떠올리시기 바랍니다
- [ ] CodeDeploy는 **빌드하지 않습니다.** 컴파일과 테스트는 [[aws-codebuild]]의 일입니다
- [ ] AWS 리소스 대상 배포는 **무료**이고 온프레미스 배포만 과금된다는 점이 함정으로 나옵니다
