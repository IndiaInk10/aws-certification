# AWS CodeCommit

> 관리형 Git 저장소

| | |
|---|---|
| **카테고리** | 11-마이그레이션-기타 |
| **배우는 모듈** | *이 코스에서는 다루지 않음 (문제은행 전용)* |
| **문제은행 출현** | 14회 |
| **상태** | - 미학습 |

## 한 줄로 말하면

**소스 코드를 저장하는 완전관리형 Git 리포지토리**입니다. 개발 파이프라인에서 **가장 앞 단계**를 맡습니다.

## 핵심 개념

- **관리형 Git 리포지토리** — 우리가 쓰던 Git 명령과 도구를 그대로 쓰면서, 리포지토리 서버를 직접 세우고 운영할 필요가 없습니다. 용량 제한 걱정 없이 확장됩니다.
- **개발 파이프라인의 시작점** — 코드가 여기에 들어오는 것을 신호로 빌드와 배포가 이어집니다. **CodeBuild → CodeDeploy → CodePipeline** 으로 이어지는 흐름의 **첫 단계**라고 기억하시면 됩니다.
- **프라이빗 저장소** — 리포지토리는 기본적으로 비공개이며, 접근 권한은 [[aws-iam]]으로 제어합니다. 사용자·그룹 단위로 어떤 리포지토리에 무엇을 할 수 있는지 정합니다.
- **저장 데이터 암호화** — 리포지토리의 데이터는 전송 중과 저장 시 모두 암호화됩니다.
- **협업 기능** — 브랜치, 풀 리퀘스트, 코드 리뷰 코멘트를 지원하고, 이벤트가 생기면 [[amazon-sns]]나 [[aws-lambda]]로 알림·자동화를 연결할 수 있습니다.

## 요금 모델

- **활성 사용자 수(월 단위)** 를 기준으로 과금합니다. 리포지토리 개수가 아니라 **실제로 사용한 사람 수**입니다.
- **일정 인원까지는 프리 티어**로 무료이며, 그 안에서 리포지토리 수와 저장 용량, 요청 수에 기본 한도가 함께 제공됩니다.
- 프리 티어를 넘으면 **추가 사용자 수 · 추가 저장 용량 · 추가 Git 요청**에 대해 요금이 붙습니다.

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[aws-codebuild]] | CodeCommit은 코드를 **저장**하고, CodeBuild는 그 코드를 **컴파일하고 테스트**합니다 |
| [[aws-codepipeline]] | CodeCommit은 파이프라인의 **한 단계(소스)** 이고, CodePipeline은 **여러 단계를 이어 주는 오케스트레이션**입니다 |
| [[amazon-s3]] | S3는 **파일을 담는 객체 스토리지**일 뿐이고, CodeCommit은 **버전 관리·브랜치·풀 리퀘스트**를 제공하는 Git 저장소입니다 |

## 시험 포인트

- [ ] 문제에 **"소스 코드 저장소"**, **"Git 리포지토리를 관리형으로"**, **"버전 관리"** 가 나오면 CodeCommit입니다
- [ ] Code 4형제의 역할을 정확히 가르시기 바랍니다 — **CodeCommit(저장) · CodeBuild(빌드·테스트) · CodeDeploy(배포) · CodePipeline(이 단계들을 잇는 파이프라인)**
- [ ] CodeCommit은 **빌드나 배포를 하지 않습니다.** "코드를 저장하고 자동으로 배포까지 한다"는 선택지는 함정입니다
- [ ] 요금은 **리포지토리 개수가 아니라 활성 사용자 수** 기준이라는 점이 자주 물어보는 지점입니다
