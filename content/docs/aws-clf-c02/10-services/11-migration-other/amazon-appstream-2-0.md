# Amazon AppStream 2.0

> 데스크톱 앱을 브라우저로 스트리밍

| | |
|---|---|
| **카테고리** | 11-마이그레이션-기타 |
| **배우는 모듈** | [[13-well-architected]] |

## 한 줄로 말하면

데스크톱 전체가 아니라 **개별 애플리케이션 하나만** 브라우저로 스트리밍해 주는 완전관리형 서비스입니다.

## 핵심 개념

- **애플리케이션 스트리밍** — 애플리케이션은 AWS에서 실행되고, 사용자에게는 **화면만 전송**됩니다. 사용자는 자기 PC에 프로그램을 설치할 필요가 없습니다.
- **브라우저만 있으면 됩니다** — HTML5를 지원하는 웹 브라우저로 접속하므로, 사양이 낮은 노트북이나 크롬북에서도 무거운 애플리케이션을 쓸 수 있습니다.
- **데이터가 사용자 기기에 남지 않습니다** — 파일과 연산이 전부 AWS 안에 머무르므로, 설계 도면이나 의료 데이터처럼 밖으로 나가면 안 되는 자료를 다루기에 적합합니다.
- **이미지와 플릿** — 배포할 애플리케이션을 담은 **이미지**를 만들고, 그 이미지를 실행하는 인스턴스 묶음인 **플릿**을 띄우는 구조입니다. 사용자 수에 맞춰 플릿 크기를 조정합니다.
- **대표 사용 사례** — 라이선스가 비싼 CAD·시뮬레이션·설계 소프트웨어를 **필요한 사람에게 필요한 기간만** 제공하거나, 교육용 소프트웨어를 학생 전체에게 한 번에 배포할 때 씁니다.

## 요금 모델

- **스트리밍 인스턴스의 실행 시간**을 기준으로 과금합니다. 인스턴스 유형이 클수록 시간당 요금이 올라갑니다.
- 플릿 유형에 따라 성격이 다릅니다 — **항상 켜져 있는(Always-On)** 방식은 접속이 빠른 대신 켜져 있는 내내 과금되고, **온디맨드** 방식은 사용자가 접속한 시간에만 과금됩니다.
- 여기에 **사용자 요금**(월 단위 사용자 수수료)이 더해집니다.
- 스트리밍되는 **애플리케이션 자체의 라이선스 비용은 별도**입니다. AWS가 대신 사 주지 않습니다.

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[amazon-workspaces]] | AppStream 2.0은 **애플리케이션 하나만** 스트리밍하고, WorkSpaces는 **데스크톱 환경 전체**를 제공합니다 |
| [[amazon-ec2]] | EC2는 서버를 빌려 내가 소프트웨어를 설치하고 관리하는 것이고, AppStream 2.0은 **최종 사용자에게 앱 화면을 배달**하는 서비스입니다 |
| [[amazon-cloudfront]] | CloudFront는 **콘텐츠 파일을 캐싱해 전달**하고, AppStream 2.0은 **실행 중인 애플리케이션 화면**을 실시간으로 전송합니다 |

## 시험 포인트

- [ ] 문제에 **"애플리케이션만 스트리밍"**, **"설치 없이 브라우저에서 실행"**, **"사용자 기기 사양에 관계없이"** 가 나오면 AppStream 2.0입니다
- [ ] **"데스크톱 환경 전체"** 라는 표현이 보이면 AppStream 2.0이 아니라 [[amazon-workspaces]]입니다. 이 구분이 핵심입니다
- [ ] **데이터가 사용자 단말에 저장되지 않는다**는 보안 이점은 두 서비스가 공통으로 갖습니다. 이것만으로는 답을 가를 수 없으니 **"데스크톱이냐 앱이냐"** 로 판단하시기 바랍니다
- [ ] 요금은 **스트리밍 인스턴스 실행 시간 + 사용자 요금**이고, **앱 라이선스는 별도**라는 점을 기억하시기 바랍니다
