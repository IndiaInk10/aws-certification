## 한 줄로 말하면

사내 웹 사이트나 SaaS만 쓰면 되는 사용자에게 **데스크톱도 앱도 아닌 브라우저 세션 하나만** 안전하게 내주는 서비스입니다.

## 핵심 개념

- **주는 것이 브라우저뿐입니다** — 최종 사용자 컴퓨팅 세 형제 중 **가장 가벼운 옵션**입니다. 데스크톱 전체도, 특정 애플리케이션도 아니고 **웹 브라우저 하나**입니다.
- **세션은 AWS에서 돌아갑니다** — 브라우징은 AWS 쪽에서 실행되고 화면만 사용자에게 전달됩니다. 그래서 **회사 데이터가 사용자의 기기에 남지 않습니다.**
- **관리하지 않는 기기에 적합합니다** — 협력업체 직원이나 개인 노트북을 쓰는 계약직처럼, 회사가 통제하지 못하는 단말에서 사내 시스템에 접근시켜야 할 때 씁니다.
- **정책으로 통제합니다** — 복사·붙여넣기, 파일 다운로드·업로드, 인쇄를 허용할지 막을지 정책으로 지정하실 수 있습니다.
- **설치할 것이 없습니다** — 사용자는 자기 브라우저로 링크에 접속하면 됩니다. VPN이나 별도 클라이언트 설치가 필요하지 않습니다.
- **완전관리형입니다** — 브라우저 이미지 관리, 패치, 확장 배포를 AWS가 맡습니다. 세션이 끝나면 그 환경은 폐기됩니다.

## 요금 모델

- **세션을 실제로 시작한 사용자 수(월 단위)** 를 기준으로 과금합니다. 계정을 만들어만 두고 쓰지 않은 사용자에게는 요금이 붙지 않습니다.
- 선결제나 최소 약정이 없어, 사용자가 늘고 줄 때 그대로 따라갑니다.

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[amazon-workspaces]] | WorkSpaces는 **데스크톱 전체**를 줍니다. "사무실 컴퓨터와 동일한 작업"이라는 지문이면 WorkSpaces입니다. Secure Browser는 브라우저만 줍니다 |
| [[amazon-appstream-2-0]] | AppStream 2.0은 **애플리케이션 하나**를 스트리밍합니다. 설계 프로그램처럼 웹이 아닌 앱이 필요하면 AppStream, 웹만 쓰면 되면 Secure Browser입니다 |
| [[amazon-cognito]] | Cognito는 애플리케이션 사용자의 **로그인과 자격 증명**을 관리합니다. Secure Browser는 접근하는 **환경 자체**를 제공합니다 |

## 시험 포인트

- [ ] 문제에 **"웹 애플리케이션만 필요", "가장 가벼운 옵션", "관리하지 않는 기기에서 사내 웹에 접근"** 이 나오면 Secure Browser입니다
- [ ] 최종 사용자 컴퓨팅은 **데스크톱 전체(WorkSpaces) → 앱 하나(AppStream 2.0) → 브라우저만(Secure Browser)** 순으로 가벼워집니다. 이 세 단계를 문제 속 요구 범위로 가르시기 바랍니다
- [ ] **데이터가 사용자 기기에 남지 않는다**는 점이 보안 요구가 걸린 문제의 정답 신호입니다
- [ ] 과금 기준은 **세션을 시작한 사용자 수**입니다
- [ ] "사무실 컴퓨터와 똑같이"라는 표현이 있으면 Secure Browser가 아니라 [[amazon-workspaces]]입니다
