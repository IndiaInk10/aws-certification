# AWS Migration Hub

> 마이그레이션 진행 상황을 한곳에서 추적

| | |
|---|---|
| **카테고리** | 11-마이그레이션-기타 |
| **배우는 모듈** | [[12-migration]] |
| **문제은행 출현** | 5회 |
| **상태** | - 미학습 |

## 한 줄로 말하면

여러 마이그레이션 도구로 나눠서 진행 중인 이전 작업의 **진행 상황을 한 화면에서 모아 보는** 중앙 추적 서비스입니다.

## 핵심 개념

- **단일 대시보드** — 마이그레이션에는 보통 여러 도구가 동시에 쓰입니다. 데이터베이스는 [[aws-dms]], 파일은 [[aws-datasync]], 서버는 또 다른 도구로 옮기죠. Migration Hub는 **이 모두의 상태를 한곳에 모아** 보여 줍니다.
- **애플리케이션 단위로 묶기** — 서버와 데이터베이스를 개별로 보는 대신 **"주문 시스템", "회계 시스템"처럼 애플리케이션 단위로 그룹**을 만들어, 그 애플리케이션이 몇 퍼센트 옮겨졌는지 확인합니다.
- **검색(디스커버리) 데이터 활용** — 온프레미스 환경을 조사해 어떤 서버가 무엇과 통신하는지, 사양은 어떤지 수집한 데이터를 여기에서 확인하고 **마이그레이션 계획을 세웁니다.**
- **직접 옮기지는 않습니다** — Migration Hub는 **추적과 계획**을 담당하고, 실제 데이터 이전은 각 마이그레이션 도구가 수행합니다. 이 역할 분담이 시험에서 갈리는 지점입니다.
- **홈 리전** — 추적 데이터를 모아 두는 **홈 리전을 하나 지정**하고, 여러 리전으로 진행되는 마이그레이션을 그곳에서 통합해 봅니다.

## 요금 모델

- **Migration Hub 자체는 무료입니다.** 진행 상황을 추적하고 대시보드를 보는 데 요금이 붙지 않습니다.
- 실제로 요금이 발생하는 것은 **각 마이그레이션 도구(DMS 등)의 사용 요금**과, **이전 완료 후 AWS에서 돌아가는 리소스 요금**입니다.

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[aws-dms]] | DMS는 **데이터베이스를 실제로 옮기는 도구**이고, Migration Hub는 **그 작업이 어디까지 진행됐는지 추적**합니다 |
| [[aws-datasync]] | DataSync는 **파일 데이터를 실제로 전송**하고, Migration Hub는 그 전송을 포함한 **전체 마이그레이션 현황을 모아 봅니다** |
| [[aws-snow-family]] | Snow Family는 **물리 장비로 데이터를 옮기는 수단**이고, Migration Hub는 **수단이 아니라 관제 화면**입니다 |

## 시험 포인트

- [ ] 문제에 **"여러 마이그레이션 도구의 진행 상황을 한곳에서 추적"**, **"마이그레이션 현황을 중앙에서 모니터링"** 이 나오면 Migration Hub입니다
- [ ] Migration Hub는 **데이터를 직접 옮기지 않습니다.** "데이터베이스를 이전한다"는 설명이 붙으면 [[aws-dms]]입니다
- [ ] **애플리케이션 단위로 묶어 진행률을 본다**는 점이 특징적인 정답 신호입니다
- [ ] **서비스 자체는 무료**이고 실제 마이그레이션 도구 요금만 낸다는 점을 기억하시기 바랍니다
