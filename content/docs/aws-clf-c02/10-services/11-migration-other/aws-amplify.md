## 한 줄로 말하면

**웹·모바일 애플리케이션의 프론트엔드와 백엔드를 빠르게 만들고 호스팅**하도록 묶어 놓은 개발 플랫폼입니다.

## 핵심 개념

- **풀스택 앱 개발 플랫폼** — 화면(프론트엔드)과 그 뒤의 기능(백엔드)을 한 도구로 구성합니다. 프론트엔드 개발자가 인프라를 직접 다루지 않고도 앱 전체를 완성할 수 있게 해 주는 것이 목표입니다.
- **백엔드 기능을 몇 줄로 붙입니다** — 사용자 인증, 데이터 저장, 파일 업로드, API, 푸시 알림 같은 기능을 명령 몇 번으로 추가합니다. 내부적으로는 Cognito·DynamoDB·S3·API Gateway 같은 서비스가 자동으로 만들어집니다.
- **Amplify Hosting** — Git 리포지토리를 연결해 두면 **코드를 푸시할 때마다 자동으로 빌드하고 배포**하며, 전 세계 CDN으로 서빙합니다. CI/CD가 내장되어 있습니다.
- **브랜치별 환경** — 기능 브랜치마다 별도 미리보기 URL을 만들어 주므로, 개발·스테이징·프로덕션을 나눠 쓰기 쉽습니다.
- **서버리스 기반** — 서버를 프로비저닝하거나 패치할 일이 없습니다. 트래픽에 따라 알아서 확장됩니다.
- **대표 사용 사례** — 스타트업의 초기 웹앱, 모바일 앱 백엔드, 정적 사이트나 단일 페이지 애플리케이션(SPA)의 배포입니다.

## 요금 모델

- **빌드에 사용한 시간(분)**, **호스팅한 데이터 저장 용량**, **서빙한 데이터 전송량**을 기준으로 과금합니다.
- Amplify가 대신 만들어 준 **백엔드 서비스들(Cognito·DynamoDB·S3 등)의 요금은 각각 따로** 청구됩니다.
- **프리 티어**가 제공되어 소규모 프로젝트는 무료 범위 안에서 시작할 수 있습니다.

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[aws-elastic-beanstalk]] | Beanstalk은 **서버 기반 웹 애플리케이션**을 코드만 올려 배포하는 플랫폼이고, Amplify는 **웹·모바일 프론트엔드 중심의 서버리스 앱**을 위한 플랫폼입니다 |
| [[amazon-s3]] | S3 정적 웹 호스팅은 **파일을 그대로 서빙**할 뿐이고, Amplify는 여기에 **빌드·CI/CD·백엔드 연동**까지 묶어 줍니다 |
| [[aws-codepipeline]] | CodePipeline은 **범용 CI/CD 오케스트레이션 도구**이고, Amplify의 CI/CD는 **프론트엔드 앱 배포에 특화**되어 이미 내장되어 있습니다 |

## 시험 포인트

- [ ] 문제에 **"웹·모바일 앱의 프론트엔드와 백엔드를 빠르게 구축"**, **"프론트엔드 개발자가 인프라 없이"**, **"Git 연동 자동 배포"** 가 나오면 Amplify입니다
- [ ] 기존 서버 기반 애플리케이션을 그대로 올리는 상황이면 Amplify가 아니라 [[aws-elastic-beanstalk]] 쪽입니다
- [ ] Amplify는 **호스팅만 하는 서비스가 아니라 백엔드 구성까지 포함**한다는 점이 함정으로 나옵니다
- [ ] Amplify가 만들어 준 **백엔드 서비스 요금은 별도로 청구**된다는 점을 기억하시기 바랍니다
