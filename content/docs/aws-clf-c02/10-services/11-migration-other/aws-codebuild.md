## 한 줄로 말하면

소스 코드를 **컴파일하고 테스트를 돌려 배포 가능한 결과물을 만들어 내는** 완전관리형 빌드 서비스입니다.

## 핵심 개념

- **빌드와 테스트 담당** — 리포지토리에서 코드를 가져와 **컴파일하고, 자동화된 테스트를 실행하고, 배포 가능한 아티팩트(패키지)** 를 만듭니다. 개발 파이프라인에서 **저장 다음, 배포 이전** 단계입니다.
- **빌드 서버를 관리하지 않습니다** — 젠킨스 서버를 세우고 패치하고 용량을 늘리던 일이 사라집니다. 빌드가 시작될 때 환경이 자동으로 준비되고, 끝나면 정리됩니다.
- **buildspec 파일로 정의** — 리포지토리에 넣어 둔 `buildspec.yml`에 **어떤 명령을 어떤 순서로 실행할지** 적어 둡니다. 빌드 절차가 코드로 관리됩니다.
- **동시 빌드로 대기가 없습니다** — 빌드 요청이 몰려도 각각 별도 환경에서 병렬로 처리되므로, 큐에서 순서를 기다리지 않습니다.
- **소스와 파이프라인 연결** — [[aws-codecommit]], S3, GitHub 등에서 소스를 가져오고, 결과는 [[aws-codepipeline]]의 빌드 단계로 이어집니다.

## 요금 모델

- **빌드에 실제로 소요된 컴퓨팅 시간(분)** 을 기준으로 과금합니다. 빌드가 돌지 않으면 요금이 발생하지 않습니다.
- 요금은 고른 **빌드 환경의 컴퓨팅 유형(작은 인스턴스일수록 저렴)** 에 따라 달라집니다.
- **프리 티어**로 매달 일정 빌드 시간이 무료로 제공됩니다.
- 유휴 상태의 빌드 서버에 대한 고정 요금은 없습니다. **쓴 만큼만 냅니다.**

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[aws-codedeploy]] | CodeBuild는 **결과물을 만드는** 단계이고, CodeDeploy는 그 결과물을 **서버에 올리는** 단계입니다 |
| [[aws-codepipeline]] | CodeBuild는 파이프라인의 **한 단계(빌드)** 이고, CodePipeline은 **소스부터 배포까지 전체 흐름을 잇는** 도구입니다 |
| [[aws-lambda]] | Lambda는 **애플리케이션 코드를 운영 중에 실행**하는 서비스이고, CodeBuild는 **배포 전에 코드를 빌드·테스트**하는 서비스입니다 |

## 시험 포인트

- [ ] 문제에 **"소스 코드를 컴파일"**, **"자동화된 테스트 실행"**, **"배포 가능한 아티팩트 생성"** 이 나오면 CodeBuild입니다
- [ ] **"빌드 서버를 프로비저닝하거나 관리하지 않는다"** 는 CodeBuild의 대표적인 이점입니다
- [ ] CodeBuild는 **배포하지 않습니다.** 배포는 [[aws-codedeploy]]의 일입니다
- [ ] 요금이 **빌드에 사용한 시간(분) 단위**라는 점, 즉 유휴 시간 요금이 없다는 점이 선택지로 나옵니다
