# AWS Snow Family

> 물리 장비로 대용량 데이터를 옮긴다 (Snowcone/Snowball/Snowmobile)

| | |
|---|---|
| **카테고리** | 02-스토리지 |
| **배우는 모듈** | [[12-migration]] |
| **문제은행 출현** | 24회 |
| **상태** | - 미학습 |

## 한 줄로 말하면

AWS가 **물리 저장 장비를 택배로 보내 주면 거기에 데이터를 담아 돌려보내는** 방식으로, 네트워크로는 감당하기 어려운 대용량 데이터를 옮기는 서비스입니다.

## 핵심 개념

- **왜 물리 배송인가** — 페타바이트급 데이터를 인터넷으로 올리면 몇 달이 걸리거나 회선 비용이 감당되지 않습니다. **장비에 담아 배송하는 편이 더 빠르고 저렴한** 구간이 존재합니다.
- **장비 종류** — 옮길 데이터 규모에 따라 고르시면 됩니다.

| 장비 | 규모 | 특징 |
|---|---|---|
| **AWS Snowcone** | 테라바이트 초반, 가장 작고 가벼움 | 드론·차량 등 공간이 좁은 현장, 열악한 환경 |
| **AWS Snowball Edge** | 수십 테라바이트급 | 스토리지 최적화형과 컴퓨팅 최적화형이 있고, **현장에서 연산도 수행**할 수 있습니다 |
| **AWS Snowmobile** | 엑사바이트급, 컨테이너 트럭 | 데이터 센터 전체를 통째로 옮기는 초대형 이전 |

- **엣지 컴퓨팅도 됩니다** — Snowball Edge는 EC2 인스턴스나 Lambda 함수를 **현장에서 실행**할 수 있어, 네트워크가 끊긴 곳에서 데이터를 먼저 처리한 뒤 보낼 수 있습니다.
- **보안** — 데이터는 장비에서 자동으로 **암호화**되고, 장비는 변조 방지 설계로 만들어져 있습니다. AWS에 도착하면 데이터를 S3로 옮긴 뒤 장비를 소거합니다.
- **일회성 작업입니다** — 데이터를 옮기고 나면 장비를 반납합니다. 상시 연결이 필요하시면 [[aws-storage-gateway]]를 쓰시면 됩니다.

## 요금 모델

- **작업 단위 서비스 요금**과 **장비를 현장에 둔 일수**를 기준으로 과금합니다. 정해진 무료 사용 일수를 넘기면 하루 단위로 추가됩니다.
- **AWS로 데이터를 들여오는 것(인바운드)에는 데이터 전송 요금이 붙지 않습니다.** 반대로 AWS에서 데이터를 꺼내 오는 작업에는 아웃바운드 요금이 붙습니다.
- 배송비는 별도이고, 옮긴 데이터가 S3에 저장된 뒤부터는 S3 요금이 붙습니다.

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[aws-storage-gateway]] | Snow는 **한 번 옮기고 끝나는 물리 배송**이고, Storage Gateway는 **네트워크로 상시 연결**하는 하이브리드 스토리지입니다. |
| **AWS DataSync** | DataSync는 **네트워크를 통해** 대량 데이터를 옮기고 동기화합니다. 회선이 충분하면 DataSync, 회선이 부족하거나 없으면 Snow입니다. |
| [[aws-direct-connect]] | Direct Connect는 온프레미스와 AWS를 잇는 **전용 회선을 까는 것**이라 준비 기간이 필요하고, Snow는 **회선 없이** 데이터를 옮깁니다. |

## 시험 포인트

- [ ] 문제에 **"페타바이트급 데이터", "네트워크 대역폭이 부족하다", "전송에 몇 달이 걸린다"** 가 나오면 Snow Family입니다
- [ ] **"물리적 디바이스를 배송받아"** 라는 표현이 보이면 바로 이 서비스입니다
- [ ] 규모로 갈립니다 — **테라바이트 초반·초소형은 Snowcone, 수십 TB는 Snowball Edge, 엑사바이트급은 Snowmobile**입니다
- [ ] **"네트워크가 없는 현장에서 데이터를 먼저 처리"** 는 Snowball Edge의 엣지 컴퓨팅 기능입니다
- [ ] Snow는 **일회성 마이그레이션**입니다. "온프레미스와 상시 연결"이면 Storage Gateway가 정답입니다
- [ ] AWS로 **들여오는 데이터 전송에는 요금이 붙지 않는다**는 점도 함께 기억해 두시기 바랍니다
