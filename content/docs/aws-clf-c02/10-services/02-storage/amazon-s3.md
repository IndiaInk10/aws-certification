## 한 줄로 말하면

파일을 **객체 단위로 통째로 넣고 꺼내는** 무제한 용량의 스토리지이고, AWS에서 가장 널리 쓰이는 서비스입니다.

## 핵심 개념

- **버킷과 객체** — 데이터를 담는 그릇이 **버킷**이고, 그 안에 들어가는 파일 하나하나가 **객체**입니다. 객체 하나의 최대 크기는 5TB이고, 전체 저장 용량에는 제한이 없습니다. 대략 100MB가 넘는 큰 객체는 **멀티파트 업로드**로 조각을 나눠 올리시면 병렬 전송으로 처리량이 오르고, 실패해도 그 조각만 다시 보내면 됩니다.
- **객체 스토리지의 성격** — 파일의 일부만 고쳐 쓰는 것이 아니라 **객체 전체를 다시 올립니다.** 그래서 자주 수정되는 데이터베이스 파일보다는 이미지·동영상·백업·로그·정적 웹 콘텐츠에 맞습니다.
- **리전에 저장되고 여러 AZ에 복제됩니다** — 버킷을 만들 때 리전을 고르면, AWS가 그 리전 안 여러 시설에 자동으로 복제해 **매우 높은 내구성**을 제공합니다.
- **스토리지 클래스** — 접근 빈도에 따라 골라 쓰시면 됩니다.

| 클래스 | 언제 쓰나 |
|---|---|
| **S3 Standard** | 자주 접근하는 데이터. 기본값 |
| **S3 Intelligent-Tiering** | 접근 패턴을 **모를 때**. AWS가 자동으로 계층을 옮겨 줍니다 |
| **S3 Standard-IA** | 가끔 접근하지만 **필요하면 즉시** 꺼내야 하는 데이터 |
| **S3 One Zone-IA** | 위와 같지만 **AZ 하나에만** 저장. 잃어도 다시 만들 수 있는 데이터 |
| **S3 Glacier 계열** | 아카이브. 자세한 내용은 [[amazon-s3-glacier]]에서 다룹니다 |

- **수명 주기 정책** — "30일이 지나면 Standard-IA로, 90일이 지나면 Glacier로, 1년이 지나면 삭제" 같은 규칙을 걸어 **비용을 자동으로 줄이실 수** 있습니다.
- **버전 관리와 접근 제어** — **버전 관리**를 켜면 실수로 인한 덮어쓰기·삭제를 이전 버전으로 되돌릴 수 있고, **MFA 삭제**까지 켜면 객체를 지울 때 MFA를 요구합니다. 버킷은 **기본적으로 비공개**이고, 정책과 **퍼블릭 액세스 차단(Block Public Access)** 으로 계정·버킷 수준에서 공개 자체를 막습니다.

## 요금 모델

- 과금 항목은 크게 네 가지입니다 — **저장 용량(GB-월)**, **요청 수**(PUT·GET 등), **아웃바운드 데이터 전송**, 그리고 IA·Glacier 클래스의 **데이터 검색 요금**입니다.
- **실제로 저장한 만큼만** 냅니다. 용량을 미리 잡아 두는 개념이 없습니다.
- **AWS로 데이터를 올리는 것(인바운드 데이터 전송)은 무료**이고, 인터넷으로 **내보내는 것(아웃바운드)** 에 요금이 붙습니다. 버킷 정책을 설정하거나 이벤트 알림을 구성하는 것 **자체에는 요금이 없습니다.**
- IA 계열은 저장 단가가 싼 대신 **최소 보관 기간과 검색 요금**이 있어, 자주 꺼내면 오히려 비싸집니다.
- 프리 티어에 매월 일정 용량의 S3 Standard 저장 공간과 일정 건수의 요청이 포함됩니다.

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[amazon-ebs]] | S3는 **객체·리전 단위**로 API를 통해 접근하고, EBS는 **블록·단일 AZ**로 EC2에 디스크로 붙습니다. OS나 DB를 올릴 수는 없습니다. |
| [[amazon-efs]] | EFS는 **파일 시스템으로 마운트**해 기존 애플리케이션이 그대로 쓰고, S3는 애플리케이션이 **API로 읽고 씁니다.** |
| [[amazon-s3-glacier]] | Glacier는 S3 안의 **아카이브 전용 클래스**입니다. 저장은 훨씬 싸지만 **꺼낼 때 시간과 검색 요금**이 듭니다. |

## 시험 포인트

- [ ] 문제에 **"객체 스토리지"**, **"무제한 용량"**, **"정적 웹사이트 호스팅"**, **"백업·미디어 파일 저장"** 이 나오면 S3입니다
- [ ] **"접근 패턴을 예측할 수 없다"** 는 곧 **Intelligent-Tiering**입니다. 거의 고정된 신호입니다
- [ ] **"자주 쓰지 않지만 필요할 때 즉시 꺼내야 한다"** 는 Standard-IA이고, **"몇 시간 기다려도 된다"** 는 Glacier입니다
- [ ] **"오래된 데이터를 자동으로 저렴한 클래스로 옮기고 싶다"** 는 **수명 주기 정책**입니다
- [ ] 객체 하나의 최대 크기는 **5TB**이고, 전체 용량은 무제한입니다
- [ ] S3 버킷은 **기본적으로 비공개**입니다. "기본적으로 퍼블릭"이라는 선택지는 오답입니다
