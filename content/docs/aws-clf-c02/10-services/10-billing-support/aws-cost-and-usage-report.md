# AWS Cost and Usage Report

> 가장 상세한 비용 원본 데이터

| | |
|---|---|
| **카테고리** | 10-비용-지원 |
| **배우는 모듈** | *이 코스에서는 다루지 않음 (문제은행 전용)* |
| **문제은행 출현** | 15회 |
| **상태** | - 미학습 |

## 한 줄로 말하면

AWS가 제공하는 **가장 상세한 원시 비용·사용량 데이터**를 파일로 만들어 **S3 버킷에 넣어 주는** 서비스입니다.

## 핵심 개념

- **가장 상세한 단일 소스** — 계정에서 발생한 모든 요금을 **라인 항목 단위**로 담습니다. 어떤 리소스가, 어느 시간에, 어떤 요금제로, 얼마를 발생시켰는지까지 들어 있습니다. 비용 데이터의 **가장 세밀한 원본**이라고 기억하시면 됩니다.
- **S3로 전달** — 보고서는 콘솔 화면이 아니라 **내가 지정한 S3 버킷**에 CSV 또는 Parquet 파일로 쌓입니다. 하루에 여러 번 갱신되며, 그달의 데이터는 확정될 때까지 계속 덮어써집니다.
- **세분화 선택** — **시간별 · 일별 · 월별** 중에서 고를 수 있고, 리소스 ID와 비용 할당 태그를 함께 넣을 수 있습니다.
- **분석 도구와 연결** — 파일이 S3에 있으므로 [[amazon-athena]]로 쿼리하거나, [[amazon-redshift]]로 적재하거나, [[amazon-quicksight]]로 대시보드를 만들어 봅니다. **직접 분석 화면을 제공하지는 않습니다.**
- **누가 쓰나** — 부서별 정산(쇼백·차지백), 대규모 조직의 상세 감사, 사내 비용 관리 시스템 연동처럼 **콘솔 화면만으로는 부족한 경우**에 씁니다.

## 요금 모델

- **보고서를 생성하고 전달받는 것 자체는 무료입니다.**
- 대신 파일이 쌓이는 **S3 스토리지 요금**은 냅니다.
- 그 파일을 Athena로 쿼리하거나 Redshift·QuickSight로 분석하면 **그 서비스들의 요금**이 따로 붙습니다.

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[aws-cost-explorer]] | CUR은 **가공되지 않은 원시 데이터를 파일로** 내려 주고, Cost Explorer는 **바로 볼 수 있는 그래프**로 보여 줍니다 |
| [[aws-budgets]] | CUR은 데이터를 **전달만** 하고 아무 알림도 보내지 않습니다. 한도 알림은 Budgets의 일입니다 |
| [[aws-pricing-calculator]] | CUR은 **실제로 청구된** 데이터이고, Pricing Calculator는 아직 쓰지 않은 것에 대한 **예상 견적**입니다 |

## 시험 포인트

- [ ] 문제에 **"가장 상세한(most detailed / comprehensive) 비용 및 사용량 데이터"** 라는 표현이 나오면 거의 확정적으로 CUR입니다
- [ ] **"S3 버킷으로 전달"**, **"Athena로 쿼리"**, **"자체 분석 도구에 데이터를 넣고 싶다"** 도 CUR의 신호입니다
- [ ] CUR 자체는 무료이고 **S3 저장 비용만 낸다**는 점이 자주 물어보는 지점입니다
- [ ] CUR에는 **대시보드나 알림 기능이 없습니다.** 시각화는 Cost Explorer, 알림은 Budgets로 갈립니다
- [ ] "요약된 화면으로 빠르게 보고 싶다"는 CUR이 아닙니다. CUR은 **원시 데이터**이므로 별도 분석이 필요합니다
