## 한 줄로 말하면

AWS의 **규정 준수 보고서와 계약서를 콘솔에서 바로 내려받는 창구**입니다.

## 핵심 개념

- **Artifact Reports** — SOC 1·SOC 2·SOC 3, PCI DSS, ISO 27001 같은 **제3자 감사 보고서**를 온디맨드로 내려받습니다. 감사팀이나 고객에게 "AWS 인프라는 이렇게 인증받았다"를 증명할 때 씁니다.
- **Artifact Agreements** — HIPAA BAA 같은 **AWS와의 계약을 검토하고 수락·관리**합니다. 보고서만 받는 곳이 아닙니다.
- **공동 책임 모델과 이어집니다** — Artifact가 증명해 주는 범위는 **AWS가 책임지는 부분, 즉 클라우드의 보안**까지입니다. 내 애플리케이션과 데이터의 규정 준수는 여전히 제 몫으로 남습니다.
- **셀프 서비스입니다** — 영업 담당자에게 요청하거나 티켓을 열 필요 없이, 콘솔에서 즉시 받으실 수 있습니다.
- **기밀 문서로 다룹니다** — 대부분 기밀 유지 조건이 걸린 문서이므로 외부에 공유할 때는 조건을 확인하셔야 합니다.

## 요금 모델

- **AWS Artifact 자체는 무료입니다.** 보고서를 몇 번 내려받아도 요금이 붙지 않습니다.
- 프리 티어라는 개념도 따로 없습니다. AWS 계정만 있으면 콘솔에서 바로 이용하시면 됩니다.

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[aws-security-hub]] | Artifact는 **AWS의 인증서와 감사 보고서**를 받는 곳이고, Security Hub는 **내 환경의 보안 상태**를 모아 보여 줍니다 |
| [[aws-config]] | Config는 **내 리소스의 구성**이 규칙을 지키는지 계속 평가합니다. 규정 준수라는 단어는 같아도 대상이 정반대입니다 |
| [[aws-trusted-advisor]] | Trusted Advisor는 내 계정을 점검해 **개선 권고**를 주는 쪽입니다 |

## 시험 포인트

- [ ] "**SOC**", "**PCI DSS**", "**ISO**", "감사 보고서를 다운로드해야 한다" → Artifact
- [ ] "**HIPAA BAA 같은 계약을 검토·수락**"도 Artifact입니다
- [ ] Artifact가 증명하는 것은 **AWS 쪽 규정 준수**입니다. 내 리소스가 규칙을 지키는지 보는 것은 Config입니다
- [ ] **무료 서비스**입니다
