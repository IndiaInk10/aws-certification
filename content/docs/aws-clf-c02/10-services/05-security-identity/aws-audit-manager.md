## 한 줄로 말하면

감사에 제출할 **증거를 사람이 모으는 대신 자동으로 모아 주고**, 감사 준비 보고서까지 만들어 주는 서비스입니다.

## 핵심 개념

- **증거 수집의 자동화** — 감사 때마다 스크린샷을 찍고 설정 값을 퍼 나르던 수작업을 없앱니다. AWS 사용 내역에서 필요한 증거를 **지속적으로** 긁어모읍니다.
- **사전 구축 프레임워크** — PCI DSS, HIPAA, GDPR, SOC 2, CIS 같은 표준에 맞춘 틀이 미리 들어 있습니다. 이 틀에 따라 어떤 증거가 필요한지 자동으로 매핑됩니다.
- **직접 만든 프레임워크도 됩니다** — 회사 내부 규정에 맞춰 통제 항목을 정의해 두고 그에 맞는 증거를 모으게 할 수 있습니다.
- **평가(assessment) 단위로 굴러갑니다** — 어떤 계정과 서비스를 대상으로 어느 프레임워크를 적용할지 정해 평가를 만들면, 그 뒤로는 증거가 계속 쌓입니다.
- **감사자에게 낼 보고서를 만듭니다** — 모은 증거를 정리한 감사 보고서를 내보낼 수 있습니다. 증거는 변조를 막기 위해 읽기 전용으로 보관됩니다.
- **규정 준수를 대신 지켜 주지는 않습니다** — 내 환경이 기준에 맞는지 **보여 줄 뿐**, 설정을 고쳐 주지 않습니다.

## 요금 모델

- **평가 대상 리소스를 평가한 건수** 기준으로 과금합니다. 수집한 증거의 양이 늘어나면 비용도 늘어납니다.
- 평가를 만들어 두고 대상이 없으면 요금이 발생하지 않습니다.
- 신규 사용자를 위한 **무료 평가 기간**이 있습니다.

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[aws-artifact]] | Artifact는 **AWS가 받은** 규정 준수 보고서(SOC, ISO 등)를 **다운로드**받는 곳이고, Audit Manager는 **내 환경의** 증거를 **수집**합니다. "AWS의 인증서를 받는다"면 Artifact, "내 감사 증거를 모은다"면 Audit Manager입니다 |
| [[aws-config]] | Config는 리소스 구성을 **규칙에 비추어 검사**하고, Audit Manager는 그 결과를 포함한 자료를 **감사 증거로 정리**합니다 |
| [[aws-security-hub]] | Security Hub는 보안 조사 결과를 모아 **운영자에게** 보여 주는 대시보드이고, Audit Manager의 결과물은 **감사자에게 제출할 보고서**입니다 |
| [[aws-trusted-advisor]] | Trusted Advisor는 모범 사례 **권장 사항**을 알려 줄 뿐 규정 준수 감사 증거를 만들지 않습니다 |

## 시험 포인트

- [ ] "**감사 증거를 자동으로 수집**", "**감사 준비**", "**감사 보고서를 만든다**" → Audit Manager
- [ ] 함정: "**AWS의** 규정 준수 보고서를 내려받는다"는 [[aws-artifact]]입니다. 방향이 반대입니다
- [ ] 함정: "리소스가 규정을 지키는지 규칙으로 검사한다"는 [[aws-config]]입니다
- [ ] Audit Manager는 증거를 모을 뿐 **설정을 교정하지 않습니다**
