## 한 줄로 말하면

AWS 계정 안에 IP 대역과 경로를 직접 정하는, **논리적으로 격리된 가상 네트워크**입니다.

## 핵심 개념

- **격리된 가상 네트워크** — 리전 안에 내 전용 네트워크를 만들고 그 안에 [[amazon-ec2]] 같은 리소스를 배치합니다. 다른 고객의 네트워크와는 논리적으로 분리되어 있습니다.
- **서브넷** — VPC의 IP 대역을 잘라 만든 구획이고, 각 서브넷은 **가용 영역 하나**에 속합니다. 인터넷에서 닿아야 하는 웹 서버는 퍼블릭 서브넷에, 데이터베이스처럼 감춰야 하는 것은 프라이빗 서브넷에 둡니다.
- **라우팅 테이블** — 어떤 목적지의 트래픽을 어디로 보낼지 정하는 규칙표입니다. 서브넷이 퍼블릭인지 프라이빗인지는 결국 이 경로가 결정합니다.
- **게이트웨이 두 가지** — **인터넷 게이트웨이**는 VPC를 **공용 인터넷**에 연결하고, **가상 프라이빗 게이트웨이(VGW)** 는 VPN을 통해 **내 사설망(온프레미스)** 에 연결합니다.
- **보안 그룹** — **인스턴스 단위** 방화벽입니다. **스테이트풀**이라 나간 트래픽의 응답은 자동으로 되돌아오고, **허용 규칙만** 쓸 수 있습니다. **새로 만든** 보안 그룹은 인바운드 전부 차단 · 아웃바운드 전부 허용으로 시작합니다. 다만 VPC에 원래 들어 있는 **기본(default) 보안 그룹**은 예외로, **같은 보안 그룹에 속한 리소스끼리는 서로 통신할 수 있는** 인바운드 규칙이 하나 들어 있습니다.
- **네트워크 ACL** — **서브넷 단위** 방화벽입니다. **스테이트리스**라 인바운드와 아웃바운드를 각각 써 주어야 하고, **허용과 거부를 모두** 쓸 수 있습니다. 기본값은 양방향 전부 허용입니다.

## 요금 모델

- **VPC, 서브넷, 라우팅 테이블, 인터넷 게이트웨이, 보안 그룹, 네트워크 ACL을 만드는 것 자체는 무료입니다.** 안에서 실행한 리소스 요금만 내시면 됩니다.
- 요금이 붙는 구성 요소는 따로 있습니다. **NAT 게이트웨이**는 시간당 요금과 처리한 데이터양 기준으로 과금합니다.
- **VPC 엔드포인트는 두 종류이고 요금이 갈립니다.** [[amazon-s3]]와 [[amazon-dynamodb]]에 쓰는 **게이트웨이 엔드포인트는 무료**이고, 그 밖의 서비스에 쓰는 **인터페이스 엔드포인트(PrivateLink)** 만 시간당 요금과 데이터 처리량으로 과금합니다.
- **데이터 전송**은 별도입니다. 인터넷으로 나가는 트래픽, 가용 영역 사이와 리전 사이를 오가는 트래픽에 요금이 붙습니다.
- **탄력적 IP(EIP)** 는 기출 기준으로 **실행 중인 인스턴스에 붙어 있는 동안에는 무료**이고, 놀리고 있으면 시간당 요금이 붙습니다. 다만 지금은 **붙어 있는 것까지 전부 과금**으로 바뀌었습니다. 두 가지를 다 알아 두시면 어느 쪽으로 나와도 대응하실 수 있습니다.

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[aws-direct-connect]] | VPC는 AWS 안의 네트워크를 만드는 쪽이고, Direct Connect는 그 VPC와 온프레미스를 **전용 회선으로 잇는** 쪽입니다 |
| [[aws-transit-gateway]] | **VPC 피어링**은 추가 소프트웨어 없이 VPC **두 개**를 프라이빗하게 잇는 방법이고, VPC가 여러 개가 되어 연결이 복잡해질 때 그 연결을 한 허브로 모아 주는 것이 Transit Gateway입니다 |
| [[aws-waf]] | 보안 그룹과 네트워크 ACL은 IP·포트 수준의 네트워크 방화벽이고, WAF는 SQL 인젝션 같은 **애플리케이션 계층(HTTP)** 공격을 막습니다 |

## 시험 포인트

- [ ] "**격리된 네트워크**", "**퍼블릭·프라이빗 서브넷**", "**IP 주소 범위를 직접 정한다**" → VPC
- [ ] **보안 그룹 = 인스턴스 단위 · 스테이트풀 · 허용만** / **네트워크 ACL = 서브넷 단위 · 스테이트리스 · 허용과 거부** — 이 여섯 단어가 가장 많이 나오는 비교입니다
- [ ] "특정 IP 주소를 **차단**해야 한다"면 보안 그룹으로는 불가능하므로 **네트워크 ACL**입니다
- [ ] **인터넷 게이트웨이 = 인터넷 연결 / 가상 프라이빗 게이트웨이 = VPN으로 온프레미스 연결** — 둘을 바꿔 놓은 선택지가 자주 나옵니다
- [ ] 함정: 서브넷은 가용 영역 하나에만 속합니다. "서브넷 하나가 여러 AZ에 걸친다"는 서술은 오답입니다
- [ ] 서비스 수준을 묻는 문제도 나옵니다. VPC·[[aws-lambda]]·[[aws-cloudtrail]]은 **리전** 서비스이고, [[aws-iam]]·[[amazon-route-53]]·[[amazon-cloudfront]]·[[aws-waf]]는 **글로벌**입니다
