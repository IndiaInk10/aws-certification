### AWS 공식 4단계 준비 플랜

| 단계 | 하는 일 | 이 사이트에서는 |
|---|---|---|
| **1. 시험 알아보기** | 시험 가이드를 검토하고 **공식 연습 문제**로 문제 유형을 파악합니다. 최대 6시간, 1~2주 차 권장 | [[exam-overview]] · [공식 연습 문제](/aws-clf-c02/quiz/0) |
| **2. 지식 보충** | 부족한 영역만 골라 학습합니다. **필수 단계가 아닙니다** | 아래 13개 모듈 |
| **3. 복습과 연습** | 도메인별 주제가 서비스와 어떻게 이어지는지 훑고, 문제로 확인하며 **응시 전략**을 익힙니다 | [[service-comparisons]] · [모의고사](/aws-clf-c02/quiz) · [[glossary]] |
