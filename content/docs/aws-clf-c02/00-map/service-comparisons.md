## [[06-storage]] · [[07-databases]] 이후

**스토리지 3종**

| | 유형 | 범위 | 특징 |
|---|---|---|---|
| [[amazon-ebs]] | 블록 | **단일 AZ** | EC2 1대에 붙는 디스크 |
| [[amazon-efs]] | 파일 | **리전** | 여러 EC2가 동시 마운트 |
| [[amazon-s3]] | 객체 | 리전 | 무제한, 웹 접근, 파일 수정 불가(덮어쓰기) |

**S3 스토리지 클래스**

| 클래스 | 접근 빈도 | 꺼내는 비용 |
|---|---|---|
| Standard | 자주 | 없음 |
| Intelligent-Tiering | **모를 때** | 없음 (모니터링 수수료) |
| Standard-IA | 가끔, 즉시 필요 | 있음 |
| One Zone-IA | 가끔, 재생성 가능 | 있음 (AZ 1개) |
| Glacier Instant | 분기 1회, 즉시 | 있음 |
| Glacier Flexible | 연 1~2회, 분~시간 | 있음 |
| Glacier Deep Archive | 연 1회 미만, **12시간** | 가장 쌈 |

**RDS 다중 AZ vs 읽기 전용 복제본**

| | 목적 | 읽기 가능 |
|---|---|---|
| 다중 AZ | **고가용성**(장애 조치) | X (대기 인스턴스) |
| 읽기 전용 복제본 | **성능**(읽기 분산) | O |

| 네트워크 인프라 | IAM 사용자·권한 |

| 관리형 서비스의 OS·패치 | 보안 그룹 설정 |

|---|---|---|
