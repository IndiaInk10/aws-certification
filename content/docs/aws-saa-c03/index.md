CLF-C02 가 "AWS에 무엇이 있는가"를 물었다면, SAA-C03 은 **"이 상황에서 무엇을 골라야 하는가"** 를 묻습니다.
서비스 이름을 아는 것만으로는 풀리지 않습니다. 대부분의 문항은 **둘 다 맞아 보이는 두 서비스**로 좁혀지고,
지문 안의 작은 조건 하나로 승부가 갈립니다.

## 시험 정보

| | |
|---|---|
| 문항 · 시간 | 65문항 / 130분 |
| 합격 기준 | 1000점 만점 중 **720점** |
| 문제 유형 | 객관식(정답 1개) · 복수 응답(정답 2개 이상) |
| 응시료 | USD 150 |
| 유효기간 | 3년 |
| 범위 내 서비스 | **129개** / 16개 카테고리 |

도메인별 비중과 **과제 명세 14개**는 [[exam-overview]]에 있습니다.

## 시작하기

> [!important] 순서가 CLF 와 다릅니다
> CLF 는 강의를 다 듣고 문제로 확인했습니다. SAA 는 반대입니다.
> **[[00-exam-strategy]]를 먼저 읽고** 시작하세요. 합격 후기 6건이 공통으로 말한 것이
> "문제 풀이가 주(主), 개념이 종(從)" 이었습니다.

1. [[00-exam-strategy]] — 문제 읽는 기술 3가지. **가장 먼저**
2. [[00-learning-path]] — 과제 명세 14개를 어떤 순서로 볼지
3. [[service-oneliners]] — 10~15분에 전체 1회독. 윤곽부터 잡기
4. [[service-comparisons]] — 실점 1순위. 선택 신호 · 탈락 신호로 가릅니다
5. [문제 풀이](/aws-saa-c03/quiz) — **1~5회차 모두 실제 출제 비중과 같은 50문항**입니다. 틀린 것은 [오답노트](/aws-saa-c03/review)에 자동으로 쌓입니다

## 담긴 것

| | 지금 | 예정 |
|---|---|---|
| 과제 명세 노트 | **14개** (공식 시험가이드 그대로) | — |
| 시험 기술 | 3가지 + 키워드 표 | 실제 문항으로 매핑 검증 |
| 한줄노트 | 시험 출현이 확인된 서비스 우선 | 범위 내 129개까지 |
| 비교노트 | **6쌍** | 문제 풀다 걸리는 쌍마다 추가 |
| 서비스 노트 | **65개** — 과제 명세가 가리키는 서비스는 모두 | 범위 내 129개까지 |
| 문제은행 | **288문항** — 실전 비중 50문항 세트 **5회차** + 모아 둔 38문항 | 6회차(복원력 13 · 비용 10) |

노트의 짜임은 CLF-C02 와 같습니다. 과제 명세 노트도 **여섯 칸**이고
(`왜 필요한가 · 새로 나오는 서비스 · 이 과제가 묻는 것 · 시험에서 갈리는 지점 · 여기까지의 지도 · 셀프 체크`),
`10-services/` 의 카테고리도 같은 열한 개라 두 자격증 사이를 오갈 때 자리가 같습니다.

> [!note] 아직 채워지는 중입니다
> 과제 명세 14개가 가리키는 서비스는 모두 노트가 있습니다.
> 그 밖의 서비스는 **뼈대를 먼저 세우고 한 겹씩 쌓는 중**이라,
> 서비스 이름이 링크가 아니라 검은 글씨로 보인다면 그 노트가 아직 안 쓰인 것입니다.
