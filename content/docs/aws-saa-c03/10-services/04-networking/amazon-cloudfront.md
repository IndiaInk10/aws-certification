> 엣지에 **복사본을 둔다**. Global Accelerator 와 가르는 것은 "캐시하느냐"

## 한 줄로 말하면

전 세계 엣지 로케이션에 콘텐츠를 캐시해 **가까운 곳에서 응답**하게 합니다. HTTP/HTTPS 전용입니다.

## 핵심 개념

- **오리진을 여러 개** 둘 수 있습니다 — 정적은 S3, 동적은 ALB 를 각각 오리진으로 등록해 **한 배포에서** 처리합니다. `정적과 동적 모두 빠르게` 의 표준 답입니다
- **오리진은 AWS 안일 필요가 없습니다** — **온프레미스 서버도 사용자 지정 오리진**이 됩니다. 인프라를 옮기지 않고 앞단만 붙이는 답이 여기서 나옵니다
- **동적 콘텐츠도 이득이 있습니다** — 캐시가 안 되더라도 엣지까지는 AWS 백본을 타므로 왕복이 빨라집니다
- **캐시 키** — 언어별로 응답이 다르면 `Accept-Language` 같은 헤더를 **캐시 키에 넣어야** 다른 언어 응답이 섞이지 않습니다
- **오리진 액세스 제어(OAC)** — CloudFront 에만 S3 버킷을 열어 줍니다. 버킷은 비공개로 두고 직접 접근을 막습니다. **최종 사용자를 구분하는 기능이 아닙니다**
- **서명 URL·서명 쿠키** — **누구에게 언제까지** 접근을 줄지 건별로 통제합니다. 프리미엄 회원, 기간 한정 대여가 이 자리입니다
- **지리적 제한** — 허용·차단 국가를 지정해 엣지에서 막습니다. 점진 출시에 씁니다
- **WAF** 를 붙일 수 있습니다. 다만 S3 직접 접근을 OAC 로 막아야 "모든 트래픽이 검사를 거친다"가 성립합니다
- **필드 수준 암호화** — HTTPS 는 전송 구간만 보호합니다. 특정 필드를 엣지에서 암호화해 **최종 애플리케이션만 풀 수 있게** 합니다
- **엣지 함수** — 요청에 맞춰 이미지 변환 같은 처리를 엣지에서 합니다
- **인증서는 us-east-1** 에 있어야 붙습니다

## 요금 모델

- **엣지에서 나가는 데이터 전송 + 요청 수** 로 붙습니다
- 오리진에서 엣지로 당기는 양이 줄어 **오리진 쪽 전송 비용이 함께 줄어듭니다.** 그래서 비용 문항에서 절감 수단으로 나옵니다
- 캐시 적중률을 올리는 것이 곧 비용 절감입니다

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[aws-global-accelerator\|Global Accelerator]] | CloudFront 는 **캐시**, GA 는 **경로**. `고정 IP`·`UDP` 면 GA, `이미지·동영상`이면 CloudFront |
| S3 Transfer Acceleration | Transfer Acceleration 은 **올리는** 것을 빠르게 합니다. 방향이 반대 |
| OAC vs 서명 URL | OAC 는 **CloudFront↔S3 사이**, 서명 URL 은 **최종 사용자** 구분 |

## 시험 포인트

- [ ] `정적과 동적 모두` → 오리진 **둘 다 등록한 CloudFront 배포**
- [ ] `백엔드는 그대로 두고 며칠 안에` → 온프레미스를 **사용자 지정 오리진**으로
- [ ] `프리미엄 고객만` · 기간 한정 → **서명 URL/쿠키** (OAC 아님)
- [ ] `S3 직접 접근 차단` → **OAC + 버킷 정책**
- [ ] `모든 트래픽을 WAF 검사` → CloudFront 에 WAF **+ OAC 로 우회로 차단**
- [ ] `국가별 점진 출시` → **지리적 제한**
- [ ] UDP·고정 IP 면 CloudFront 탈락
