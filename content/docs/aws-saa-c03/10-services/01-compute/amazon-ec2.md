> 가상 서버. SAA 는 "무엇을 띄우나"가 아니라 **어느 계열·어느 요금 모델·어디에 배치**를 묻는다

## 한 줄로 말하면

가상 서버입니다. 시험은 **인스턴스 계열 선택 · 요금 모델 선택 · 배치 그룹**을 묻고, 대부분 "수평 확장이 답"이라는 방향으로 갑니다.

## 핵심 개념

**인스턴스 계열 — 첫 글자가 곧 용도**

| 계열 | 강한 곳 | 지문의 신호 |
|---|---|---|
| T | 버스트 가능 범용 | 평소 한가하고 가끔 튄다 |
| M | 균형 잡힌 범용 | 특별한 요구가 없다 |
| **C** | 컴퓨팅 최적화 | `CPU 집약적` · 배치 · 게임 서버 |
| **R · X** | 메모리 최적화 | `인메모리` · 대용량 캐시 |
| I · D | 스토리지 최적화 | `높은 로컬 IOPS` |
| P · G · Inf | 가속 컴퓨팅 | `GPU` · 머신러닝 |

- **Graviton(ARM)** 은 같은 성능에 더 쌉니다. `가격 대비 성능을 올려라` 의 단골 답입니다
- M 계열에서 메모리가 병목이면 **R 계열로 옮기는 것**이 답입니다. 크기를 키우면 CPU 값까지 함께 냅니다
- **EC2 기본 지표에 메모리가 없습니다.** 메모리를 보려면 CloudWatch 에이전트를 깔아야 합니다

**요금 모델**

| | 언제 | 할인 |
|---|---|---|
| 온디맨드 | 예측 불가 · 단기 | — |
| **Savings Plans** | 1~3년 **금액** 약정. 계열·리전·Fargate·Lambda 까지 유연 | 최대 72% |
| 예약 인스턴스 | 1~3년 **특정 인스턴스** 약정 | 최대 72% |
| **스팟** | **중단돼도 되는** 작업 | 최대 90% |
| 전용 호스트 | 물리 서버 독점. **소켓·코어 기반 라이선스** | — |

- **Compute Savings Plans 는 계열·크기를 바꿔도** 적용됩니다. EC2 Instance Savings Plans 는 계열 안에서만 유연합니다
- **용량을 확보**하는 도구는 요금 약정이 아니라 **온디맨드 용량 예약**이고, 용량은 **가용 영역 단위**입니다
- 전용 호스트와 전용 인스턴스는 다릅니다 — **소켓·코어가 보이는 것은 전용 호스트**뿐이라 그 기준 라이선스를 얹을 수 있습니다

**스팟을 더 파고들면**

- 중단 **2분 전 경고**가 옵니다. 그 신호를 받아 작업을 저장하고 빠지는 구성이 정답으로 나옵니다
- **스팟 요청을 취소해도 실행 중인 인스턴스는 안 죽습니다.** 인스턴스를 따로 종료해야 합니다 — 이 순서가 함정입니다
- **스팟 플릿** — 여러 인스턴스 유형·AZ 에 걸쳐 요청합니다. 할당 전략 중 **capacityOptimized** 가 중단 가능성이 가장 낮아 `중단을 최소화` 의 답입니다
- 스팟은 **중단돼도 되는** 작업에만 — 상태를 인스턴스에 들고 있는 워크로드에 스팟을 붙이는 보기는 오답입니다

**배치 그룹**

| | 무엇 | 한계 |
|---|---|---|
| **클러스터** | 같은 랙에 몰아 **지연 최소화·10Gbps**. HPC · EFA | **랙이 죽으면 전부** — 단일 AZ |
| **분산(Spread)** | 서로 다른 하드웨어에 흩어 **동시 장애 차단** | **AZ 당 7대**까지 |
| **파티션** | 파티션끼리 랙을 공유하지 않음 | 100대 이상 확장 — HDFS · Cassandra · Kafka |

- `최저 지연·최고 대역폭` → 클러스터 / `동시 장애가 없어야` → 분산 / `대규모 분산 시스템` → 파티션
- **분산의 AZ 당 7대 제한**이 문항이 됩니다 — 20대를 분산 배치 그룹 하나에 넣는 보기는 성립하지 않습니다

**IP 와 ENI**

- 인스턴스를 **중지했다 켜면 퍼블릭 IP 가 바뀝니다.** 고정이 필요하면 **탄력적 IP**(계정당 5개, 상향 요청 가능)인데, AWS 는 대신 **DNS 이름이나 로드 밸런서**를 권합니다
- **ENI** — 가상 네트워크 카드입니다. **AZ 에 묶여 있고**, 인스턴스를 옮겨 붙일 수 있어 **IP·MAC 을 유지한 채 장애 조치**하는 구성에 씁니다

**최대 절전(Hibernate)** — 메모리 내용을 **암호화된 루트 EBS 볼륨에 저장**했다가 그대로 복원합니다. 부팅과 초기화가 긴 애플리케이션에 씁니다. **루트 볼륨이 암호화되어 있어야 하고**, RAM 150GB 이하, 최대 60일입니다.

**사용자 데이터** — 부팅 시 한 번 실행되는 스크립트입니다. **첫 시작에만** 돕니다.

**그 밖에** — 인스턴스 스토어는 **휘발성**(멈추면 사라짐) · 배치 그룹과 별개로 **여러 AZ 에 걸치는 것이 고가용성의 기본** · 자격 증명은 키가 아니라 **IAM 역할**로

## 요금 모델

- 실행 중인 시간에 붙습니다. **중지하면 인스턴스 요금이 멈추지만 EBS 볼륨은 계속 청구**됩니다
- **연결되지 않은 탄력적 IP** 에 요금이 붙습니다 — 인스턴스를 중지하면 오히려 과금이 시작됩니다
- 데이터 전송은 **나가는 쪽**과 **AZ 를 넘는 쪽**에 붙습니다

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[aws-lambda\|AWS Lambda]] | 15분을 넘거나 상태가 필요하면 EC2 |
| [[aws-fargate\|AWS Fargate]] | 컨테이너인데 서버를 관리하기 싫으면 Fargate |
| 전용 호스트 vs 전용 인스턴스 | 소켓·코어가 보이는 쪽이 **전용 호스트** |

## 시험 포인트

- [ ] `CPU 집약적` → C · `인메모리` → R · `GPU` → P/G
- [ ] `비용은 줄이고 성능은 유지` → Graviton
- [ ] `계열을 바꿀 수도 있다` → **Compute** Savings Plans
- [ ] `용량을 확보` → 온디맨드 용량 예약 (AZ 까지 지정)
- [ ] `중단돼도 된다` → 스팟 / `상태 저장 DB` → 스팟 오답
- [ ] **수직 확장(크기 키우기)은 대개 오답**입니다. 지문이 "나눌 수 없다"고 못 박은 경우만 예외
- [ ] `최저 지연 · HPC` → **클러스터** 배치 그룹
- [ ] `동시 장애가 없어야` → **분산** 배치 그룹 (**AZ 당 7대** 제한)
- [ ] `HDFS · Kafka 대규모` → **파티션** 배치 그룹
- [ ] `스팟 중단을 최소화` → 스팟 플릿 **capacityOptimized**
- [ ] 스팟 요청 취소 ≠ 인스턴스 종료
- [ ] 재시작하면 퍼블릭 IP 가 바뀐다 → **탄력적 IP** 또는 로드 밸런서
- [ ] `부팅·초기화가 너무 길다` → **최대 절전** (루트 볼륨 암호화 필수)
- [ ] `IP 를 유지한 채 다른 인스턴스로` → **ENI 재연결**
