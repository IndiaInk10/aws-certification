> 대수를 자동으로 조절한다. **어떤 지표로, 언제, 어떻게 교체하느냐**가 전부 문항이 된다

## 한 줄로 말하면

인스턴스 대수를 정책에 따라 늘리고 줄이며, **비정상 인스턴스를 교체**합니다. SAA 는 조정 정책 선택과 상태 확인 유형을 묻습니다.

## 핵심 개념

**조정 정책 네 가지**

| | 언제 |
|---|---|
| **대상 추적** | `CPU 를 50% 로 유지`. 가장 단순하고 가장 자주 정답 |
| 단순 · 단계 조정 | 경보 하나에 몇 대를 더할지 직접 정할 때 |
| **예약 조정** | `매월 1일 자정` 처럼 **시점을 아는** 경우 |
| **예측 조정** | 과거 패턴을 학습해 **미리** 늘린다. 추세를 분석할 인력이 없을 때 |

- 급증 시점을 **알고 있으면 예약**, **모르지만 패턴이 있으면 예측**입니다. 동적 조정은 부하가 온 **뒤에** 반응하므로 `즉시 100%` 같은 지문에서는 늦습니다
- **큐 기반 워커**는 CPU 가 아니라 **큐에 쌓인 메시지 수(인스턴스당 백로그)** 를 지표로 삼습니다. CPU 는 큐가 밀려도 안 오릅니다

**상태 확인 유형이 갈림길입니다**

- 기본값 **EC2** 는 하이퍼바이저가 보는 인스턴스 상태만 봅니다. 인스턴스가 켜져 있으면 정상입니다
- **ELB** 로 바꿔야 로드 밸런서가 애플리케이션을 비정상으로 판정했을 때 교체합니다. `프로세스만 죽었는데 교체가 안 된다` 는 지문의 답입니다

**빠르게 늘려야 할 때**

- ASG 확장은 **인스턴스 부팅 시간만큼 늦습니다.** 미리 구운 AMI 로 부팅을 줄입니다
- **웜 풀** — 미리 초기화해 중지 상태로 대기시킵니다. 큰 AMI 를 대량 프로비저닝할 때 초기화 시간이 사실상 사라집니다
- 그래도 부족하면 컴퓨팅 자체를 **Lambda·Fargate** 로 바꾸는 것이 답입니다

**운영**

- **인스턴스 새로 고침** — 시작 템플릿의 AMI 를 올리고 **정상 비율을 지키며 조금씩 교체**합니다. 무중단 AMI 교체의 표준
- **수명 주기 후크** — 시작·종료 도중에 인스턴스를 잠시 붙잡아 등록·해제 같은 작업을 끝냅니다. **종료 시점 보고**는 후크가 없으면 놓칩니다
- **여러 AZ 에 걸치게** 하는 것이 고가용성의 기본이고, **AZ 마다 같은 대수**여야 한 AZ 를 잃어도 용량이 유지됩니다
- **리전을 넘지 못합니다.** 두 리전에 걸친 하나의 ASG 는 만들 수 없습니다
- **쿨다운** — 조정 직후 일정 시간(기본 300초) 동안 추가 조정을 막아 **출렁임(thrashing)** 을 방지합니다. `계속 늘렸다 줄였다 한다` 의 답
- **종료 정책** — 줄일 때 누구를 내보낼지 정합니다. 기본은 **AZ 균형을 먼저 맞추고**, 그다음 오래된 시작 구성·다음 청구 시간이 가까운 것 순입니다. `AZ 가 한쪽으로 몰린다` 면 이 규칙이 배경입니다
- **인스턴스 보호**를 걸면 축소 대상에서 제외됩니다

## 요금 모델

- Auto Scaling 자체는 **추가 요금이 없습니다.** 띄운 인스턴스 값만 냅니다
- 그래서 비용 최적화는 **무엇을 띄우느냐**로 합니다 — 기본 부하는 Savings Plans, 여유분은 스팟이라는 혼합이 자주 정답입니다

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| AWS Auto Scaling | 여러 서비스를 함께 조절하는 상위 도구. 시험은 대개 EC2 Auto Scaling |
| ELB | ELB 는 **분산**, ASG 는 **대수 조절**. 둘을 붙여야 고가용성이 됩니다 |
| 예약 vs 예측 | 시점을 **알면** 예약, **모르지만 패턴이 있으면** 예측 |

## 시험 포인트

- [ ] `프로세스만 죽었는데 교체가 안 된다` → 상태 확인을 **ELB** 로
- [ ] `매월 1일 자정` 처럼 시점 명시 → **예약 조정** (동적 조정은 늦다)
- [ ] `추세를 분석할 인력이 없다` + 사전 준비 → **예측 조정**
- [ ] 큐 소비자는 **큐 길이**로 확장 (CPU 아님)
- [ ] `무중단으로 AMI 교체` → **인스턴스 새로 고침**
- [ ] `시작·종료 직후에 보고` → **수명 주기 후크**
- [ ] ASG 는 **리전을 못 넘습니다**
