> 서버 없이 코드만. **15분 한도**와 **VPC 연결의 부작용**이 SAA 의 갈림길이다

## 한 줄로 말하면

이벤트가 오면 코드를 실행하고, **없으면 비용이 0** 입니다. `운영 오버헤드가 가장 적은` 이 나오면 후보 1순위이지만 **한도에 걸리는지**를 먼저 확인해야 합니다.

## 핵심 개념

**한도가 답을 정합니다**

| | 한도 |
|---|---|
| 실행 시간 | **최대 15분(900초)** |
| 메모리 | 128MB ~ **10GB** |
| 배포 패키지 | 50MB(zip) · 압축 해제 250MB |
| 기본 동시 실행 | 리전당 **1,000**(상향 요청 가능) |
| `/tmp` | 512MB ~ 10GB |

- **15분을 넘는 작업은 Lambda 가 아닙니다** — Fargate·Batch·EC2 쪽이거나, [[aws-step-functions\|Step Functions]] 로 단계를 쪼갭니다
- 메모리를 올리면 **CPU 도 함께** 올라갑니다. 메모리를 줄이면 오히려 느려지고, 총 비용이 늘기도 합니다 — [[aws-compute-optimizer\|Compute Optimizer]] 가 적정값을 알려 줍니다
- **동시 실행 한도**에 걸려 일이 유실되면 **앞에 SQS 큐를 넣어** 완충합니다. 반대로 특정 함수가 한도를 독점하지 못하게 **예약된 동시성**으로 상한을 걸 수 있습니다
- **계층(Layer)** — 공통 라이브러리를 따로 떼어 여러 함수가 공유합니다. 패키지 크기 한도를 넘길 때의 답

**호출과 실패 처리**

- **이벤트 소스** — S3 이벤트, SQS 큐, DynamoDB 스트림, EventBridge 규칙, API Gateway 등
- **실패 시 대상(on-failure destination)** 으로 SQS 를 지정하면 실패한 호출이 **버려지지 않고 남습니다**
- **SNS 가 직접 부르는 구조는 실패하면 사라집니다.** 사이에 SQS 를 끼워 넣어야 "반드시 처리"가 성립합니다
- **함수 URL** — 함수 하나에 HTTPS 주소를 바로 붙입니다. 웹훅 수신처럼 엔드포인트 하나만 필요할 때 API Gateway 없이 끝납니다

**VPC 연결**

- 기본적으로 VPC **밖에서** 돕니다. VPC 안의 자원이나 Direct Connect·VPN 너머에 닿으려면 **VPC 에 연결하는 설정이 전제**입니다
- 연결하면 **동시 실행마다 서브넷의 프라이빗 IP 를 씁니다.** 함수와 동시성이 늘면 IP 가 먼저 바닥납니다 — 서브넷 크기를 미리 넉넉히 잡아야 합니다

**성능**

- **프로비저닝된 동시성** — 미리 준비시켜 콜드 스타트를 없앱니다. 라이브러리를 많이 로드하는 함수에서 효과가 큽니다
- **RDS Proxy** — Lambda 가 DB 커넥션을 소진하는 것을 막습니다. 콜드 스타트와 커넥션 수립은 **다른 문제**라 둘 다 필요할 때가 있습니다

**엣지에서 도는 함수 — 둘이 갈립니다**

| | 언제 |
|---|---|
| **CloudFront Functions** | **1ms 미만** 시작 · 초당 수백만 · 경량 JS. **헤더 조작·URL 재작성·간단한 리디렉션** |
| **Lambda@Edge** | 초당 수천 · Node.js/Python · **네트워크 접근·큰 처리 가능**. 요청/응답 4단계 모두에서 |

- `헤더만 살짝 바꾸면 된다` → CloudFront Functions(싸고 빠름) / `외부를 호출하거나 무거운 처리` → Lambda@Edge

**권한** — 함수가 다른 서비스를 부를 때는 **실행 역할**, 다른 서비스가 이 함수를 부르게 허용할 때는 **리소스 기반 정책**입니다. 방향이 반대이니 섞지 마세요.

## 요금 모델

- **요청 수 × 실행 시간 × 할당 메모리** 로 붙습니다. 호출이 없으면 0 입니다
- 그래서 `몇 시간씩 요청이 없다` 는 지문에서 상시 컨테이너보다 압도적으로 쌉니다
- 프로비저닝된 동시성은 **대기 중에도 요금**이 붙습니다 — 콜드 스타트를 없애는 대가입니다

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[aws-fargate\|AWS Fargate]] | 15분을 넘거나 기존 컨테이너를 그대로 쓰면 Fargate |
| [[aws-batch\|AWS Batch]] | 오래 도는 대량 배치는 Batch |
| [[amazon-ec2\|EC2]] | 커널·에이전트까지 통제해야 할 때만 |

## 시험 포인트

- [ ] `15분을 넘는다` → Lambda 탈락
- [ ] `동시 실행 한도로 유실` → 앞에 **SQS**
- [ ] `모든 알림이 결국 처리되어야` → SNS 와 Lambda 사이에 **SQS**
- [ ] VPC 연결 시 **서브넷 IP 고갈**을 미리 고려
- [ ] 웹훅 수신처럼 엔드포인트 하나 → **함수 URL**
- [ ] EventBridge 가 함수를 부르게 하려면 **리소스 기반 정책**(실행 역할 아님)
