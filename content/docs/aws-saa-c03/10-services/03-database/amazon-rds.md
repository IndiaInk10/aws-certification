> **다중 AZ 는 가용성, 읽기 전용 복제본은 성능.** 이 한 줄이 RDS 문항의 절반이다

## 한 줄로 말하면

관계형 데이터베이스를 관리형으로 돌립니다. 백업·패치·장애 조치를 AWS 가 맡습니다.

## 핵심 개념

**다중 AZ vs 읽기 전용 복제본 — 절대 섞으면 안 됩니다**

| | 다중 AZ 배포 | 읽기 전용 복제본 |
|---|---|---|
| 목적 | **고가용성** | **읽기 성능** |
| 복제 | **동기** | **비동기** |
| 평상시 | 대기본은 **트래픽을 받지 않습니다** | 읽기를 받습니다 |
| 장애 시 | **자동 장애 조치**(DNS 가 그대로) | 수동 승격 |
| 리전 | 같은 리전 | **다른 리전 가능** |

- `읽기 부하가 커서 느리다` → **읽기 전용 복제본**. 다중 AZ 를 켜는 보기는 성능에 도움이 되지 않습니다
- `AZ 장애에도 자동 복구` → **다중 AZ**
- `리전 장애 대비` → **다른 리전에 읽기 전용 복제본** → 필요 시 승격
- 둘은 **동시에 쓸 수 있고**, 실제 시험 정답이 "다중 AZ + 읽기 전용 복제본"인 경우가 많습니다

**백업과 복구**

- **자동 백업** — 보존 기간 안에서 **특정 시점 복구(PITR)** 가 됩니다. `실수로 지운 데이터를 5분 전으로` 의 답
- **수동 스냅샷** — 내가 지울 때까지 남습니다. 장기 보관·계정 간 공유용
- **스냅샷을 다른 리전으로 복사**해 DR 을 만듭니다. 암호화된 스냅샷을 공유하려면 **고객 관리형 KMS 키**여야 합니다

**성능**

- **스토리지 유형** — gp3(범용) · io1/io2(높은 IOPS 보장). `일관된 높은 IOPS` 면 프로비저닝 IOPS
- **인스턴스 크기 조정**은 다운타임이 생깁니다 — 다중 AZ 면 장애 조치를 이용해 짧게 줄입니다
- 읽기 전용 복제본 **엔드포인트를 애플리케이션이 따로 써야** 효과가 납니다. 그냥 만들기만 하면 읽기가 가지 않습니다

**암호화** — 생성 시에 켭니다. **나중에 켜려면 스냅샷을 암호화해 복원**해야 합니다. 이 사실이 문제로 나옵니다.

**RDS Proxy**

- 연결을 풀링해 **연결 폭주**를 막습니다. Lambda 가 RDS 를 부르는 구성의 표준 답입니다
- **장애 조치 시간을 최대 66% 줄입니다** — 애플리케이션은 프록시만 보고 있어 뒤에서 바뀌는 것을 몰라도 됩니다
- **IAM 인증을 강제**하고 자격 증명을 [[aws-secrets-manager\|Secrets Manager]] 에서 가져옵니다. `DB 비밀번호를 코드에서 없애야` 와 함께 나옵니다
- **VPC 안에서만** 접근됩니다

**그 밖에**

- **스토리지 자동 조정** — 용량이 차면 알아서 늘립니다. `디스크 부족으로 장애가 났다` 의 답
- **SSH 로 접속할 수 없습니다.** OS 에 손댈 수 없는 것이 관리형의 대가입니다 — 그게 필요하면 RDS Custom 이나 EC2 자체 설치입니다
- **IAM 데이터베이스 인증**으로 비밀번호 없이 토큰으로 붙을 수 있습니다(MySQL·PostgreSQL)

## 요금 모델

- **인스턴스 시간 + 스토리지 + I/O + 백업 초과분** 입니다
- **다중 AZ 는 대략 두 배**입니다 — 대기본이 하나 더 도니까요. `비용 최소` 와 `고가용성` 이 함께 있으면 절충을 보는 문제입니다
- **예약 인스턴스**로 1·3년 약정 할인을 받습니다
- 개발·테스트 DB 를 **밤에 중지**하면 인스턴스 요금이 멈춥니다(스토리지는 계속)

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[amazon-aurora\|Aurora]] | 더 빠르고 복제본 15개·자동 확장 스토리지. 서버리스 옵션 |
| [[amazon-dynamodb\|DynamoDB]] | 스키마 없는 키-값. 한 자리 밀리초·무제한 확장 |
| [[amazon-elasticache\|ElastiCache]] | 앞단 캐시. 읽기 부하를 근본에서 덜어 냅니다 |

## 시험 포인트

- [ ] `읽기 성능` → **읽기 전용 복제본** (다중 AZ 아님)
- [ ] `AZ 장애에도 자동으로` → **다중 AZ**
- [ ] `5분 전으로 복구` → **자동 백업 + PITR**
- [ ] `Lambda 에서 연결이 폭주` → **RDS Proxy**
- [ ] 암호화는 **생성 시** — 나중이면 스냅샷 복원
- [ ] `다른 리전 DR` → 리전 간 읽기 전용 복제본 또는 스냅샷 복사
- [ ] `디스크가 차서 장애` → **스토리지 자동 조정**
- [ ] `비밀번호를 코드에서 없애야` → **IAM 인증** 또는 **RDS Proxy + Secrets Manager**
- [ ] OS 접근·SSH 가 필요하다는 요구 → RDS 로는 불가
