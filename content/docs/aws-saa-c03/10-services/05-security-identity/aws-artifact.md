> **규정 준수 서류 창구**. 기술이 아니라 **문서**를 요구하는 지문의 답

## 한 줄로 말하면

AWS 가 받은 감사 보고서와 인증서를 **직접 내려받는 셀프 서비스 저장소**입니다.

## 핵심 개념

- **AWS Artifact Reports** — SOC · PCI DSS · ISO 같은 **제3자 감사 보고서**를 콘솔에서 바로 받습니다. AWS 영업에 요청하는 절차가 없습니다
- **AWS Artifact Agreements** — BAA 같은 **온라인 계약**을 검토하고 체결·철회합니다
- 공동 책임 모델에서 **AWS 가 책임지는 쪽을 증명하는 서류**가 여기 있습니다. 내 워크로드의 규정 준수는 여전히 내 몫입니다
- 보고서에는 기밀 조건이 붙습니다. 받아서 감사 기관에 제출하는 용도입니다

## 요금 모델

- 별도 요금이 없습니다. 계정만 있으면 받습니다

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[aws-config\|AWS Config]] | **내 리소스**가 규칙에서 벗어났는지 봅니다. Artifact 는 **AWS 의 서류**입니다 |
| [[aws-cloudtrail\|CloudTrail]] | 누가 무엇을 했는지 **기록**입니다. 감사 보고서가 아닙니다 |
| [[amazon-inspector\|Inspector]] | 취약점을 **점검**합니다. 서류를 주지 않습니다 |

## 시험 포인트

- [ ] `감사 기관이 SOC 보고서를 요구` · `규정 준수 증빙 서류` → **Artifact**
- [ ] 서류를 묻는데 암호화·탐지 서비스를 고르는 보기는 질문에 답하지 않은 것입니다
