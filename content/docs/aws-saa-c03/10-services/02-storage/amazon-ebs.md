> EC2 한 대에 붙는 블록 볼륨. SAA 에서는 "어느 유형인가"와 "AZ 를 못 넘는다"가 문항이 된다

## 한 줄로 말하면

EC2 인스턴스에 디스크처럼 붙는 **블록 스토리지**이고, **가용 영역 하나에 묶여 있습니다.** SAA 는 볼륨 유형 선택과 스냅샷 운영을 묻습니다.

## 핵심 개념

**볼륨 유형 — IOPS 인가 처리량인가**

| 유형 | 성격 | 언제 |
|---|---|---|
| **gp3** | 범용 SSD. **IOPS·처리량을 용량과 따로** 올린다 | 기본값. 대부분 여기 |
| gp2 | 범용 SSD. IOPS 가 **용량에 묶여** 있다 | 옛 기본값 |
| **io1 · io2** | 프로비저닝 IOPS SSD | `수만 IOPS` · 미션 크리티컬 DB |
| st1 | 처리량 최적화 HDD | 빅데이터·로그 같은 **순차** 읽기 |
| sc1 | 콜드 HDD | 거의 안 건드리는 데이터 |

- **`초당 트랜잭션 수`면 IOPS(SSD), `초당 MB`면 처리량**입니다. 두 요구는 다릅니다.
- gp2 에서는 용량을 늘려야 IOPS 가 올랐지만 **gp3 는 그 관계가 끊겨 있습니다.** 비용 절감 문항의 단골이 gp2 → gp3 전환입니다.
- 요구가 1,000 IOPS 정도인데 io2 를 고르는 것은 **돈만 더 쓰는 과한 선택**입니다.

**AZ 를 못 넘습니다**

- 볼륨은 **한 가용 영역 안에서만** 인스턴스에 붙습니다. 다른 AZ 로 옮기려면 **스냅샷을 떠서 그 AZ 에 새로 만들어야** 합니다.
- `다른 AZ 의 인스턴스에 붙인다` 는 보기는 그대로 오답입니다.

**스냅샷**

- **증분**입니다. 바뀐 블록만 저장되지만 계속 쌓이므로 정리가 필요합니다 — **Data Lifecycle Manager** 로 자동화합니다
- **교차 리전·교차 계정 복사** 가 되고, 이것이 DR 의 기본 재료입니다
- 스냅샷에서 만든 볼륨은 **처음 읽을 때 블록을 가져오는 지연 로딩** 때문에 초반 성능이 낮습니다. **빠른 스냅샷 복원(FSR)** 을 켜면 처음부터 제 성능이 납니다
- 암호화된 스냅샷을 다른 계정과 공유하려면 **KMS 키 권한도 함께** 줘야 합니다. AWS 관리형 기본 키로 암호화된 것은 애초에 공유가 안 됩니다

**그 밖에**

- **다중 연결(Multi-Attach)** — io1·io2 를 **같은 AZ 의 여러 Nitro 인스턴스**에 동시에 붙입니다. 쓰는 쪽에서 동시성 제어를 해야 합니다
- **인스턴스 스토어와 다릅니다** — 인스턴스 스토어는 호스트에 직접 붙어 가장 빠르지만 **인스턴스가 멈추면 사라집니다**
- 리전 수준에서 **EBS 기본 암호화**를 켜면 새로 만드는 볼륨이 자동으로 암호화됩니다

## 요금 모델

- **프로비저닝한 용량** 기준입니다. 쓴 만큼이 아니라 **잡아 둔 만큼** 냅니다 — S3·EFS 와 다른 지점입니다
- io1·io2 는 용량과 **프로비저닝한 IOPS 에 각각** 요금이 붙습니다
- 스냅샷은 증분이지만 저장한 만큼 계속 과금됩니다
- **인스턴스를 지워도 볼륨이 남아 계속 청구되는 것**이 조용히 새는 대표적인 비용입니다

## 헷갈리는 것과 구분

| 비교 대상 | 차이 |
|---|---|
| [[amazon-efs\|Amazon EFS]] | EBS 는 **블록·단일 AZ·한 인스턴스**, EFS 는 **파일·리전·여러 인스턴스** |
| 인스턴스 스토어 | EBS 는 영구, 인스턴스 스토어는 **휘발성**. `가장 높은 I/O` 이면서 `사라져도 된다`면 인스턴스 스토어 |
| gp3 vs io2 | 수만 IOPS 가 필요하지 않으면 gp3 로 충분합니다 |

## 시험 포인트

- [ ] `여러 인스턴스가 동시에` → EBS 가 아니라 EFS (다중 연결은 같은 AZ · Nitro · io 계열 한정)
- [ ] `용량은 그대로인데 IOPS 만 올리고 싶다` → gp3
- [ ] `복제 직후부터 일관되게 높은 I/O` → 빠른 스냅샷 복원
- [ ] `다른 AZ 로 옮긴다` → 스냅샷 → 그 AZ 에 새 볼륨
- [ ] 암호화 스냅샷 공유는 **스냅샷 + KMS 키** 둘 다
