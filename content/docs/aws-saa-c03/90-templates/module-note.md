## 3. 이 과제가 묻는 것

공식 시험가이드의 지식·기술 항목을 우리 말로 다시 쓴다. 서비스 설명은 여기 쓰지 않는다 —
그건 `10-services/` 몫이고, 여기는 **언제 고르는가**만 다룬다.

## 5. 여기까지의 지도

주황색이 이번 과제에서 새로 나온 서비스입니다.

```d2
classes: {
  new: {
    style: {
      fill: "#ff9900"
      stroke: "#232f3e"
      stroke-width: 2
      font-color: "#111111"
    }
  }
}

grid-columns: 1
grid-gap: 16

# 과제마다 아래 모양으로 한 덩이씩 쌓는다.
# 이번에 새로 나온 과제에만 `*.class: new` 를 붙이고, 지난 과제는 붙이지 않는다.
#
# "N.N 과제 이름": {
#   grid-rows: 2          한 줄에 최대 4개가 되도록 ceil(서비스 수 / 4)
#   *.width: 190
#   *.style.font-size: 12
#   *.class: new          이번 과제에만
#
#   서비스 이름
#   서비스 이름
# }
```
