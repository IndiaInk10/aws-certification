> [!important] 2.2 를 앞으로 당기세요
> 도메인 2 는 과제가 **둘뿐**이라 개당 밀도가 압도적입니다.
> 그중 [[05-high-availability\|2.2 고가용성·내결함성]] 안에 **DR 전략 4종과 RPO/RTO 가 통째로** 들어 있습니다.

> 반대로 도메인 3 은 비중 2위(24%)지만 **5개로 잘게 쪼개져** 개당 부담이 가장 낮습니다.
> 비중이 크다고 겁먹고 여기부터 파면 시간을 잘못 씁니다.

## 문제를 푸는 순서

SAA 는 지문이 깁니다. 위에서부터 읽으면 조건을 놓칩니다.

| 순서 | 하는 일 |
|---|---|
| 1 | **마지막 문장부터** 읽습니다 — 무엇을 우선하라는 조건절이 거기 있습니다 |
| 2 | 그 조건의 **키워드**를 잡습니다 (`가장 비용 효율적인` · `운영 오버헤드가 가장 적은` …) |
| 3 | 명백한 오답을 **먼저 지웁니다** |
| 4 | 남은 **2개**를 1번의 조건으로 비교합니다 |
| 5 | 오래 걸리면 표시해 두고 넘어갑니다 (130분이라 돌아올 시간이 있습니다) |

자세한 것은 [[00-exam-strategy]]에 있습니다. **서비스 노트보다 먼저 읽으세요.**

## 자주 나오는 함정

- **둘 다 맞는 답** — 대부분의 문항이 2개로 좁혀집니다. 승부는 조건절 한 줄에서 납니다
- **FSx 변종 구분** — Lustre / Windows File Server / ONTAP / OpenZFS. 이름만 같지 용도가 다릅니다
- **VPC 엔드포인트 2종** — Gateway(S3·DynamoDB만, 무료) vs Interface(그 외, 시간당 과금)
- **연결 방식 3종** — VPC 피어링 / Transit Gateway / PrivateLink
- **문제 세트 운** — 어려운 세트를 받을 수 있습니다. 어려운 쪽을 기본값으로 두고 준비하세요
