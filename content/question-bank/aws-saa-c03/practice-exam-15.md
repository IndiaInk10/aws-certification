> a) **Workload Discovery on AWS**를 사용해 워크로드 아키텍처 다이어그램을 생성한다
> b) Systems Manager Inventory의 상세 보고서로 맵 뷰를 만든다
> c) Step Functions로 정보를 수집해 다이어그램을 수동으로 그린다
> d) AWS X-Ray로 워크로드를 보고 관계도를 그린다
>> [!success]- Answer

> [!question] 대량 데이터를 병렬 처리하는 워크로드를 EC2에서 돌리며, **노드 그룹이 같은 기반 하드웨어를 공유하지 않도록** 구성할 수 있어야 합니다. 어떤 솔루션이 요구 사항을 충족합니까?
> a) EC2 인스턴스를 **분산 배치 그룹(spread placement group)**에서 실행한다
> b) EC2 인스턴스를 서로 다른 계정으로 나눈다
> c) EC2 인스턴스를 전용 테넌시로 구성한다
> d) EC2 인스턴스를 공유 테넌시로 구성한다
>> [!success]- Answer
>> a) EC2 인스턴스를 **분산 배치 그룹(spread placement group)**에서 실행한다
>> **왜 이 답인가** — 분산 배치 그룹은 인스턴스를 **각기 다른 랙(하드웨어)에 배치**해 동시 장애 위험을 줄입니다. 요구가 이 기능의 정의 그대로입니다.
>> **나머지가 아닌 이유** — 전용 테넌시는 **다른 고객과 하드웨어를 공유하지 않는 것**이지 내 인스턴스끼리 분산하는 것이 아닙니다. 계정을 나누는 것은 배치와 무관합니다.

> a) Lake Formation 블루프린트로 데이터베이스 데이터를 S3 데이터 레이크로 수집하고, **Lake Formation으로 열 수준 접근 제어**를 적용한 뒤 QuickSight에서 Athena를 데이터 원본으로 쓴다
> b) AWS Glue Studio로 데이터를 S3로 수집하고 QuickSight 사용자에게 IAM 정책을 붙여 열 수준 접근을 통제한다
> c) Glue Elastic Views로 구체화된 뷰를 만들고 S3 버킷 정책으로 열 수준 접근을 통제한다
> d) Amazon EMR로 데이터베이스에서 QuickSight SPICE 엔진으로 직접 수집하며 필요한 열만 포함한다
>> [!success]- Answer
>> a) Lake Formation 블루프린트로 데이터베이스 데이터를 S3 데이터 레이크로 수집하고, **Lake Formation으로 열 수준 접근 제어**를 적용한 뒤 QuickSight에서 Athena를 데이터 원본으로 쓴다
>> **왜 이 답인가** — **열 수준 권한은 Lake Formation의 기능**입니다. 이미 Lake Formation을 쓰고 있으므로 수집도 블루프린트로 하고 조회는 Athena를 통해 하면 권한이 자동으로 적용됩니다.
>> **나머지가 아닌 이유** — IAM 정책이나 S3 버킷 정책은 **객체 단위**라 열 단위 제어를 표현하지 못합니다. EMR로 직접 수집하면 권한 통제가 사라집니다.

> b) DynamoDB Standard 테이블 클래스로 온디맨드 모드를 구성한다

> d) Standard-IA 테이블 클래스로 온디맨드 모드를 구성한다
>> [!success]- Answer
>> a) **DynamoDB Standard 테이블 클래스에 프로비저닝된 읽기·쓰기**를 구성하고 **오토 스케일링**의 최대 용량을 정한다

> b) API Gateway로 WebSocket API를 설계하고 프라이빗 VPC 링크를 만든다
> c) REST API를 설계하고 API Gateway가 ECS에 접근하도록 보안 그룹을 만든다
> d) WebSocket API를 설계하고 보안 그룹을 만든다
>> [!success]- Answer

> a) Amazon S3 File Gateway
> b) 볼륨 게이트웨이
> c) 테이프 게이트웨이

> [!question] 고가용성 **ElastiCache for Redis** 솔루션을 설계합니다. 장애가 나도 성능 저하나 데이터 손실이 없어야 하며 **노드 수준과 리전(가용 영역) 수준의 고가용성**이 필요합니다. 어떤 솔루션이 요구 사항을 충족합니까?
> a) **여러 노드를 포함한 샤드로 구성된 다중 AZ Redis 복제 그룹**을 사용한다

> d) 오토 스케일링을 켠 다중 노드 샤드를 사용한다
>> [!success]- Answer
